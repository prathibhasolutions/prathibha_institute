Section A: Programming Questions

Attempt any SEVEN of the following questions. Each question carries 10 marks. (7 x 10 = 70 Marks)

1. Write a C program that takes an integer from the user and checks if it is even or odd using the modulo operator.

Example: 
Enter an integer: 27
27 is an odd number.

2. Write a C program to check if a given number is a prime number or not. The program should use a loop to check for factors.

Example 1: 
Enter a positive integer: 29
29 is a prime number.
Example 2: 
Enter a positive integer: 10
10 is not a prime number.

3. Write a C program to find the length of a string using a pointer, without using the `strlen()` library function.

Example: 
Enter a string: C Programming
Length of the string is: 13

4. Write a C program to reverse the elements of an integer array. For example, if the array is `[1, 2, 3, 4, 5]`, the output should be `[5, 4, 3, 2, 1]`.

Example Input & Output: 
Original array: 10 20 30 40 50 
Reversed array: 50 40 30 20 10

5. Using nested `for` loops, write a C program to print the following inverted right-angled triangle pattern of asterisks:

* * * * *
* * * *
* * *
* *
*

6. Define a structure named `Book` with members `title` (char array), `author` (char array), and `price` (float). Write a C program to read details for 3 books into an array of structures and then display them in a formatted way.

Example Output Format: 
Book 1:
Title: The C Programming Language
Author: Dennis Ritchie
Price: 450.50
... (and so on for Book 2 and Book 3)

7. Write a C program to find the sum of all digits of an integer using a recursive function.

Example: 
Enter a number: 1234
Sum of digits is: 10

8. Write a C program to copy the contents of one file (e.g., "source.txt") to another file (e.g., "destination.txt").

Instructions: 
1. Create a file "source.txt" with some text in it.
2. Run the program.
3. Check that a new file "destination.txt" is created with the same content.
Program should print "File copied successfully." upon completion.

9. Write a C program to concatenate two strings into a single string without using the `strcat()` library function.

Example Input & Output: 
Enter first string: Hello 
Enter second string: World!
Concatenated string: Hello World!

10. Write a C program that takes an integer from 1 to 7 from the user and prints the corresponding day of the week (1 for Sunday, 2 for Monday, etc.) using a `switch` statement. Include a default case for invalid input.

Example: 
Enter day number (1-7): 3
Day is: Tuesday

Section B: Theory Questions

Answer any FOUR of the following questions. Each question carries 5 marks. (4 x 5 = 20 Marks)

11. What are static variables in C? Explain their scope, lifetime, and default initial value.

12. Explain the purpose of `malloc()` and `free()` functions in C for dynamic memory allocation. Which header file must be included to use them?

13. What is a `union` in C? How is it different from a `struct`? Provide a simple example declaration for both.

14. Explain the relationship between arrays and pointers in C. Why can an array name be treated as a constant pointer?

15. What are the different file opening modes in C? Describe the functionality of "r", "w", and "a".
