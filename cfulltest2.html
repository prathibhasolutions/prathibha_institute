Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Write a program to print even numbers from 1 to n.
    Input: 10
    Output: 2 4 6 8 10
  2. Write a program to count digits in a number.
    Input: 4562
    Output: 4
  3. Find sum of all elements in an array.
    Input: [1,2,3,4]
    Output: 10
  4. Convert a string to uppercase.
    Input: c language
    Output: C LANGUAGE
  5. Print Fibonacci series up to n terms.
    Input: 5
    Output: 0 1 1 2 3
  6. Search an element in an array.
    Input: [1,3,5,7], 5
    Output: Found at index 2
  7. Find the length of a string without using strlen().
    Input: hello
    Output: 5
  8. Check whether a character is a vowel using if-else.
    Input: a
    Output: Vowel
  9. Find largest number in a 2D array.
    Input: 2x2 matrix
    Output: Largest = ___
  10. Copy contents of one file to another.
    Output: file copied successfully
