Python MCQs and Programming Questions

Multiple Choice Questions (MCQs)

Programming Questions


  1. Write a program to check if a number is positive, negative or zero using if-else.
    Example:
    Input: -5
    Output: Negative
  2. Write a program to print the first N even numbers using a loop.
    Example:
    Input: 5
    Output: 2 4 6 8 10
  3. Write a program to print a half pyramid pattern using '*'.
    Example:
    Input: 3
    Output:
    *
    **
    ***
  4. Write a program to print multiplication table of a number using a loop.
    Example:
    Input: 3
    Output:
    3 6 9 12 15 18 21 24 27 30
  5. Write a program to check if a string is a palindrome.
    Example:
    Input: madam
    Output: Palindrome
  6. Write a program to remove duplicates from a list.
    Example:
    Input: [1, 2, 2, 3, 1]
    Output: [1, 2, 3]
  7. Write a program to count the number of vowels in a string.
    Example:
    Input: "education"
    Output: 5
  8. Write a program to store student marks in a dictionary and display them.
    Example:
    Input: {'John': 85, 'Amit': 92}
    Output: John: 85, Amit: 92
  9. Write a program to swap first and last elements of a tuple.
    Example:
    Input: (1, 2, 3, 4)
    Output: (4, 2, 3, 1)
  10. Write a program to find the intersection of two sets.
    Example:
    Input: {1,2,3} & {2,3,4}
    Output: {2, 3}
