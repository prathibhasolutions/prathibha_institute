Topic: ArrayList

Write a Java program to create an ArrayList of integers, add the numbers 10, 20, 30, 40, 50 to it. Then remove the element at index 2 and print the remaining elements.

Expected Output: 
[10, 20, 40, 50]

Topic: HashSet

Expected Output: 
HashSet: [Apple, Banana, Cherry, Date]
Number of unique elements: 4

Topic: LinkedList

Topic: ArrayList

Topic: HashSet

Write a Java program to create two HashSets: Set1 = {1, 2, 3, 4} and Set2 = {3, 4, 5, 6}. Find and print the intersection (common elements) and union (all elements) of both sets.

Expected Output: 
Intersection: [3, 4]
Union: [1, 2, 3, 4, 5, 6]

Topic: LinkedList
