JavaScript DOM - Introduction

What is the DOM?

DOM stands for Document Object Model. It is a programming interface provided by browsers that allows JavaScript to interact with and modify the content, structure, and style of a webpage.

Why is the DOM important?
  • It allows dynamic content updates without reloading the page.
  • JavaScript can access and change HTML elements and attributes.
  • It enables event handling like clicks, form submissions, etc.
  • DOM helps make webpages interactive and user-friendly.
How is the DOM structured?

The DOM represents a webpage as a tree of objects (nodes). Each element (like <div>, <p>, <img>) is a node in the tree. JavaScript can traverse and modify these nodes using DOM APIs.

DOM Access Methods

JavaScript provides several methods to access and manipulate elements in the DOM. These methods help us select HTML elements based on their ID, class, tag, or CSS selector.

1. getElementById()

Returns the element that has the specified ID. 

document.getElementById("myId");

Note: Returns a single element or null if not found.

2. getElementsByClassName()

Returns a live HTMLCollection of all elements with the specified class name. 

document.getElementsByClassName("myClass");

Note: You can access elements using array index: [0], [1], etc.

3. getElementsByTagName()

Returns a live HTMLCollection of all elements with the specified tag name (e.g., "p", "div"). 

document.getElementsByTagName("p");
4. querySelector()

Returns the first element that matches the specified CSS selector. 

document.querySelector(".myClass");

Tip: Use #id for ID, .class for class, or any valid CSS selector.

5. querySelectorAll()

Returns a static NodeList of all elements matching the specified CSS selector. 

document.querySelectorAll("div.note");

Note: Use forEach() to loop through the NodeList.

Example: getElementById()

Access a paragraph element by its ID and change its text.

<p id="demo">Hello</p>

<script>
  document.getElementById("demo").innerText = "Hello from JavaScript!";
</script>
Example: getElementsByClassName()

Change the text of the first element with class 'note'.

<p class="note">Note 1</p>
<p class="note">Note 2</p>

<script>
  let notes = document.getElementsByClassName("note");
  notes[0].innerText = "Updated Note 1";
</script>
Example: getElementsByTagName()

Change the first paragraph tag.

<p>Paragraph 1</p>
<p>Paragraph 2</p>

<script>
  let paras = document.getElementsByTagName("p");
  paras[0].style.color = "blue";
</script>
Example: querySelector()

Select the first element with class 'highlight' and make it bold.

<div class="highlight">First</div>
<div class="highlight">Second</div>

<script>
  document.querySelector(".highlight").style.fontWeight = "bold";
</script>
Example: querySelectorAll()

Change the text color of all elements with class 'color-box'.

<span class="color-box">One</span>
<span class="color-box">Two</span>

<script>
  let boxes = document.querySelectorAll(".color-box");
  boxes.forEach(function(box) {
    box.style.color = "green";
  });
</script>
The document Object

In JavaScript, document is the entry point to the DOM. It represents the entire HTML page loaded in the browser. Using the document object, we can access and manipulate all HTML elements, attributes, content, and styles.

document.title

Returns or sets the title of the document (seen in the browser tab).

<script>
  document.title = "My Custom Title";
</script>
document.body

Returns the <body> element of the document.

<script>
  document.body.style.backgroundColor = "lightyellow";
</script>
document.URL

Returns the complete URL of the current page.

<script>
  console.log(document.URL);
</script>
document.getElementById()

Selects a single element by its ID and allows us to manipulate it.

<p id="greet">Hi</p>

<script>
  document.getElementById("greet").innerText = "Hello, DOM!";
</script>
document.write()

Writes content directly to the document. It should only be used during page load. Using it after the page is loaded can overwrite the entire page. 

<script>
  document.write("<h2>Welcome to JavaScript DOM</h2>");
</script>
document.all (Deprecated)

Returns a collection of all HTML elements.
⚠️ Not recommended for modern use. 

<script>
  console.log(document.all[0]);  // Prints <!DOCTYPE html>
</script>
1. What are DOM Elements?

DOM elements are the HTML elements represented as JavaScript objects in the browser. Each HTML tag is a node, and when parsed by the browser, it becomes an element node that can be accessed and manipulated using JavaScript.

2. Accessing DOM Elements

You can access DOM elements using various methods:

  • document.getElementById()
  • document.getElementsByClassName()
  • document.getElementsByTagName()
  • document.querySelector()
  • document.querySelectorAll()
<div id="demo">Hello</div>
<script>
  let el = document.getElementById("demo");
  console.log(el.innerText);
</script>
3. Modifying Element Content

You can change the text or HTML inside an element using:

  • innerText
  • innerHTML
  • textContent (includes hidden text)
<p id="greeting">Welcome</p>

<script>
  let p = document.getElementById("greeting");
  p.innerText = "Hello, User!";
</script>
4. Creating and Appending Elements

You can dynamically create and add new elements using:

  • document.createElement()
  • parent.appendChild()
  • parent.append()
<div id="container"></div>

<script>
  let newEl = document.createElement("p");
  newEl.innerText = "This is a new paragraph.";
  document.getElementById("container").appendChild(newEl);
</script>
5. Removing Elements

You can remove elements from the DOM using:

  • element.remove()
  • parent.removeChild(child)
<div id="removeMe">Delete me</div>

<script>
  document.getElementById("removeMe").remove();
</script>
6. Replacing Elements

Use replaceChild() to replace an element with another. 

<div id="parent">
  <p id="old">Old Paragraph</p>
</div>

<script>
  let newPara = document.createElement("p");
  newPara.innerText = "New Paragraph";
  let old = document.getElementById("old");
  let parent = document.getElementById("parent");
  parent.replaceChild(newPara, old);
</script>
7. Attributes and Classes

Use the following methods to work with element attributes:

  • setAttribute()
  • getAttribute()
  • removeAttribute()
  • classList.add(), classList.remove()
<img id="myImg" src="old.jpg">

<script>
  let img = document.getElementById("myImg");
  img.setAttribute("src", "new.jpg");
  img.classList.add("rounded");
</script>
8. Styling Elements

Use element.style to change inline styles of elements dynamically. 

<h2 id="heading">Hello</h2>

<script>
  let h = document.getElementById("heading");
  h.style.color = "red";
  h.style.fontSize = "30px";
</script>
9. Element Properties

DOM elements have many useful properties like:

  • tagName – returns tag name
  • className – returns class value
  • id – returns id of the element
<div id="box" class="container"></div>

<script>
  let box = document.getElementById("box");
  console.log(box.tagName);     // DIV
  console.log(box.className);   // container
  console.log(box.id);          // box
</script>

1. innerHTML

element.innerHTML gets or sets the HTML content inside an element.

  • It can return or inject HTML.
  • It replaces the entire content inside the element.
<div id="content"></div>

<script>
  document.getElementById("content").innerHTML = "<b>Hello</b> World!";
</script>
2. outerHTML

element.outerHTML gets or sets the HTML including the element itself. 

<div id="box">Old</div>

<script>
  let box = document.getElementById("box");
  box.outerHTML = "<section>New Content</section>";
</script>
3. textContent vs innerText

Both return text, but behave differently:

  • textContent returns all text, including hidden (invisible via CSS).
  • innerText respects CSS visibility and formatting.
<div id="demo" style="display:none;">Hidden Text</div>

<script>
  console.log(document.getElementById("demo").textContent);  // Outputs "Hidden Text"
  console.log(document.getElementById("demo").innerText);    // Outputs ""
</script>
4. insertAdjacentHTML()

Inserts HTML relative to an existing element. It accepts two arguments:

  • position: "beforebegin", "afterbegin", "beforeend", "afterend"
  • html: the HTML string to insert
<div id="container">Start</div>

<script>
  let box = document.getElementById("container");
  box.insertAdjacentHTML("beforeend", "<span> End</span>");
</script>
5. document.write()

This method writes directly to the HTML stream but is not recommended for use after the page has loaded. 

<script>
  document.write("<h3>This is written to the document</h3>");
</script>
6. Replacing HTML dynamically

You can combine multiple DOM methods to replace or update part of the DOM with custom HTML content. 

<div id="main"><p>Old paragraph</p></div>

<script>
  document.getElementById("main").innerHTML = "<h3>New heading inserted</h3>";
</script>
7. Real-World Use Case: Load Comments

Load dynamic HTML content from server or user input using innerHTML or insertAdjacentHTML(). 

<div id="comments"></div>

<script>
  let comment = "<p><strong>John:</strong> Nice tutorial!</p>";
  document.getElementById("comments").insertAdjacentHTML("beforeend", comment);
</script>

      alert("Hello " + name);

1. What is DOM Animation?

DOM Animation refers to programmatically changing an element’s styles or positions over time using JavaScript. This includes:

  • Moving, rotating, resizing elements
  • Fading, sliding, or scaling
  • Using JavaScript timers or `requestAnimationFrame()`
2. Using setInterval()

Move an element continuously by updating its position every few milliseconds. 

<div id="box" style="width:50px;height:50px;position:absolute;background:red;"></div>

<script>
  let pos = 0;
  const box = document.getElementById("box");
  const move = setInterval(() => {
    if (pos >= 300) clearInterval(move);
    else {
      pos += 2;
      box.style.left = pos + "px";
    }
  }, 10);
</script>
3. Using setTimeout()

setTimeout() can be used recursively for a frame-by-frame animation. 

<div id="circle" style="width:40px;height:40px;border-radius:50%;background:blue;position:absolute;"></div>

<script>
  let left = 0;
  function animate() {
    if (left >= 300) return;
    left += 3;
    document.getElementById("circle").style.left = left + "px";
    setTimeout(animate, 20);
  }
  animate();
</script>
4. CSS Transitions + JavaScript

You can use CSS transitions for smooth animation and control them via JavaScript. 

<div id="fadeBox" style="width:100px;height:100px;background:green;transition:all 1s;"></div>
<button onclick="animateFade()">Animate</button>

<script>
  function animateFade() {
    let el = document.getElementById("fadeBox");
    el.style.transform = "translateX(200px)";
    el.style.opacity = "0.5";
  }
</script>
5. Using requestAnimationFrame()

This is the most efficient and smoothest way to perform animations in the browser. 

<div id="animateBox" style="width:60px;height:60px;background:orange;position:absolute;"></div>

<script>
  let x = 0;
  function moveBox() {
    if (x >= 300) return;
    x += 2;
    document.getElementById("animateBox").style.left = x + "px";
    requestAnimationFrame(moveBox);
  }
  requestAnimationFrame(moveBox);
</script>
6. Toggle Animation with Button

Create an animation that starts/stops with a button click. 

<div id="ball" style="width:30px;height:30px;background:black;border-radius:50%;position:absolute;"></div>
<button onclick="startStop()">Toggle Move</button>

<script>
  let running = false;
  let posX = 0;
  let interval;
  function startStop() {
    if (!running) {
      interval = setInterval(() => {
        posX += 2;
        document.getElementById("ball").style.left = posX + "px";
      }, 10);
      running = true;
    } else {
      clearInterval(interval);
      running = false;
    }
  }
</script>
7. Mini Project: Bouncing Ball

Animate a ball bouncing left to right using `requestAnimationFrame()`. 

<div id="bounceBall" style="width:40px;height:40px;background:red;border-radius:50%;position:absolute;"></div>

<script>
  let bx = 0;
  let direction = 1;
  function bounce() {
    if (bx >= 300 || bx <= 0) direction *= -1;
    bx += 3 * direction;
    document.getElementById("bounceBall").style.left = bx + "px";
    requestAnimationFrame(bounce);
  }
  bounce();
</script>
1. What Are DOM Events?

Events are actions that occur in the browser (e.g., user clicks, typing, submitting forms). JavaScript allows you to listen and respond to these events.

  • Examples: click, mouseover, keydown, submit, etc.
2. Using onclick Attribute

Directly set event handler in HTML tag. 

<button onclick="sayHello()">Click Me</button>

<script>
  function sayHello() {
    alert("Hello from button!");
  }
</script>
3. addEventListener()

The modern and preferred way to attach events in JavaScript. 

<button id="btn">Greet</button>

<script>
  document.getElementById("btn").addEventListener("click", function() {
    alert("Greetings!");
  });
</script>
4. The event Object

The event object (usually e) gives details about the triggered event.

  • e.target – the element that triggered the event
  • e.type – type of event (click, mouseover, etc.)
  • e.key – which key was pressed (in keyboard events)
<button id="showEvent">Show Event</button>

<script>
  document.getElementById("showEvent").addEventListener("click", function(e) {
    console.log("Event type:", e.type);
    console.log("Clicked on:", e.target);
  });
</script>
5. Mouse Events

Common mouse-related events:

  • click
  • dblclick
  • mouseover / mouseout
  • mousedown / mouseup
<div id="hoverBox" style="width:100px;height:100px;background:lightgray;"></div>

<script>
  document.getElementById("hoverBox").addEventListener("mouseover", function() {
    this.style.backgroundColor = "skyblue";

  document.getElementById("hoverBox").addEventListener("mouseout", function() {

6. Keyboard Events

Detect when a user presses a key in an input field or anywhere on the document.

  • keydown
  • keyup
  • keypress (deprecated)

Monitor user interaction with form elements:

  • submit – when the form is submitted

1. What is addEventListener()?

It’s a method that attaches an event handler to a DOM element without overwriting existing handlers.

It allows multiple listeners for the same event.

2. Syntax

element.addEventListener(event, handler, useCapture);

  • event: Type of event like 'click', 'keydown'
  • handler: The function to run
  • useCapture: Optional boolean for event phase (default: false)
document.getElementById("btn").addEventListener("click", function() {
  alert("Button clicked!");
});
3. Attaching Multiple Events

You can add more than one event of the same type or different types. 

let box = document.getElementById("box");

box.addEventListener("mouseover", () => {
  box.style.backgroundColor = "lightgreen";
});

box.addEventListener("mouseout", () => {
  box.style.backgroundColor = "white";
});
4. Anonymous vs Named Functions

Using a named function allows removal of the listener later. 

function showAlert() {
  alert("Hello!");
}
button.addEventListener("click", showAlert);
5. Using this in Event Listeners

Inside a regular function, this refers to the element triggering the event. 

document.getElementById("demo").addEventListener("click", function() {
  this.style.color = "blue";
});
6. Passing Arguments to Event Handlers

Use an arrow or anonymous function to pass arguments. 

let greet = (name) => alert("Hello, " + name);
document.getElementById("btn").addEventListener("click", function() {
  greet("Student");
});
7. Removing Event Listener

Use removeEventListener() with the same function reference used in addEventListener(). 

function logMessage() {
  console.log("Clicked!");
}
let btn = document.getElementById("logBtn");

btn.addEventListener("click", logMessage);

// To remove later:
btn.removeEventListener("click", logMessage);
8. One-Time Event Listener

Use `{ once: true }` as the third parameter to auto-remove after first trigger. 

document.getElementById("onceBtn").addEventListener("click", () => {
  alert("This works only once!");
}, { once: true });

1. What is DOM Navigation?

DOM Navigation (Traversal) means accessing and moving through nodes in the DOM tree using JavaScript.

  • Upward: to parent
  • Downward: to children
  • Sideways: to siblings
2. Accessing Parent Node

Use .parentNode or .parentElement to access the parent of a given element. 

<div id="outer">
  <p id="child">Child Element</p>
</div>

<script>
  const child = document.getElementById("child");
  console.log(child.parentNode); // returns outer div
</script>

childNodes returns all nodes (including text), while children returns only element nodes. 

<ul id="list">
  <li>One</li>
  <li>Two</li>
</ul>

<script>
  const ul = document.getElementById("list");
  console.log(ul.childNodes);  // Includes text nodes
  console.log(ul.children);    // Only 
  •  elements
</script>

    1. What are DOM Collections?

    DOM collections are list-like objects that contain groups of elements retrieved from the DOM. Examples: HTMLCollection and NodeList.

    • Returned by functions like getElementsByTagName or querySelectorAll
    • Can be looped, indexed, and manipulated
    2. Types of DOM Collections
    • HTMLCollection: live collection of elements
    • NodeList: static list of nodes

    Returned by different DOM methods:

    3. HTMLCollection vs NodeList

    Both are array-like, but there are differences:

    • HTMLCollection: Live (updates when DOM changes)
    • NodeList: Static (doesn't update after creation)
    • NodeList may contain other node types (e.g. text nodes)
    4. Live vs Static Collections
