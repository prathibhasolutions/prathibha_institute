Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Check whether a number is even or odd using if-else.
    Example:
    Input: 5
    Output: Odd
  2. Print the multiplication table of a number using loop.
    Example:
    Input: 4
    Output: 4 8 12 16 20 24 28 32 36 40
  3. Find factorial of a number using loop.
    Example:
    Input: 5
    Output: 120
  4. Count the number of vowels in a string.
    Example:
    Input: hello
    Output: 2
  5. Reverse a given array.
    Example:
    Input: [1, 2, 3, 4]
    Output: [4, 3, 2, 1]
  6. Check whether a string is palindrome or not.
    Example:
    Input: madam
    Output: Palindrome
  7. Swap two numbers using pointers.
    Example:
    Input: 10, 20
    Output: 20, 10
  8. Read a file and count number of lines.
    Example:
    Input File: data.txt
    Output: 5 lines
  9. Store and print 5 student marks using array.
    Example:
    Input: 45, 67, 89, 32, 50
    Output: 45 67 89 32 50
  10. Print a number pyramid using nested loops.
    Example:
    Input: 3
    Output:
    1
    1 2
    1 2 3
