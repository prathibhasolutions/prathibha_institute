Python MCQs and Programming Questions

Multiple Choice Questions (MCQs)

Programming Questions (Medium to Hard Level)


  1. Write a function that returns all anagrams from a list of words for a given word.
    Example:
    Input: "listen", ["enlist", "google", "inlets", "banana"]
    Output: ['enlist', 'inlets']
  2. Write a program to count the frequency of each word in a paragraph using dictionary.
    Example:
    Input: "Python is fun and Python is powerful"
    Output: {'Python': 2, 'is': 2, 'fun': 1, 'and': 1, 'powerful': 1}
  3. Create a class Employee with attributes name, salary. Add methods to increase salary by percentage and display updated details.
  4. Implement a class Circle with methods to calculate area and circumference. Use constructor to set radius.
    Formula: Area = πr², Circumference = 2πr
  5. Write a class Time with hours and minutes. Overload the + operator to add two time objects.
  6. Write a function that reads a text file and returns the longest word.
    Example Output: "programming"
  7. Create a class Student with a static variable to count total number of objects created.
  8. Implement a function to reverse each word in a sentence using string functions.
    Example:
    Input: "Python is great"
    Output: "nohtyP si taerg"
  9. Write a class Account with deposit, withdraw, and balance check methods. Raise a custom exception for insufficient funds.
  10. Write a program to merge two sorted lists into a new sorted list without using sort().
    Example:
    Input: [1, 3, 5], [2, 4, 6]
    Output: [1, 2, 3, 4, 5, 6]
