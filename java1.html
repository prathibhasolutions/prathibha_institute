Java Question Paper

Section A: Multiple Choice Questions (MCQs)

1. Which of these is a valid keyword in Java?

Correct Answer: interface

2. Which method must be implemented by a class implementing the Runnable interface?

Correct Answer: run()

3. What is the size of an int variable in Java?

Correct Answer: 4 bytes

4. Which of these is not a Java feature?

Correct Answer: Use of pointers

5. Which class is used to take input from the user?

Correct Answer: Scanner

6. Which is the default value of a boolean variable in Java?

Correct Answer: false

7. Which operator is used by Java run-time implementations to free memory?

Correct Answer: None of the above

8. What is the base class of all classes in Java?

Correct Answer: Object

9. Which of the following is not a primitive data type in Java?

Correct Answer: Float

10. What does JVM stand for?

Correct Answer: Java Virtual Machine

11. Which package contains the Random class?

Correct Answer: java.util

12. Which keyword is used to inherit a class in Java?

Correct Answer: extends

13. Which of these is used to handle exceptions in Java?

Correct Answer: All of these

14. Which of these is not a loop structure in Java?

Correct Answer: foreach

15. What will `System.out.println(10 + 20 + "Hello")` print?

Correct Answer: 30Hello

16. What does the 'static' keyword denote?

Correct Answer: Method belongs to class

17. Which is not a valid access modifier in Java?

Correct Answer: internal

18. Which of the following is a marker interface?

Correct Answer: Serializable

19. Which function is called when an object is created?

Correct Answer: constructor

20. Which keyword is used to refer to the current object?

Correct Answer: this

21. Which method is used to find the length of a string in Java?

Correct Answer: length()

22. Which of these is not a Java loop keyword?

Correct Answer: loop

23. Java uses which memory management model?

Correct Answer: Garbage Collection

24. Which method is called before an object is garbage collected?

Correct Answer: finalize()

25. Which keyword is used to prevent inheritance?

Correct Answer: final

26. Which is the correct way to create an ArrayList in Java?

Correct Answer: List list = new ArrayList();

27. Which class is the parent of all exceptions in Java?

Correct Answer: Throwable

28. Which interface provides capability to store elements using key-value pairs?

Correct Answer: Map

29. Which exception is thrown when a divided by zero occurs?

Correct Answer: ArithmeticException

30. Which keyword is used to define a constant in Java?

Correct Answer: static final
