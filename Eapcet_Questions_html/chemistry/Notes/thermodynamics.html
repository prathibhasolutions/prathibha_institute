⚡ First Law of Thermodynamics
Zeroth Law: If A is in thermal equilibrium with C, and B is in thermal equilibrium with C → A and B are in thermal equilibrium. First Law: ΔU = q + W q = heat absorbed by system (+ve: added, −ve: released) W = work done on system (+ve: compression, −ve: expansion) Work of expansion: W = − ∫ pext dV
Work Expressions (Summary)
#ConditionExpression
iIrreversible expansion at constant P\(W = -p_{ext} \times \Delta V\)
iiReversible isothermal (ideal gas)\(W = 2.303\,nRT\log\dfrac{V_2}{V_1} = 2.303\,nRT\log\dfrac{p_1}{p_2}\)
iiiReversible adiabatic\(W = \dfrac{nR(T_1 - T_2)}{\gamma - 1}\)
ivIrreversible adiabatic\(W = -p_{ext} \times \dfrac{nR(p_2T_1 - p_1T_2)}{p_1 p_2}\)
vFree expansion (in vacuum)\(p_{ext} = 0; \quad W = 0, \quad \Delta U = 0\)
Maximum work is obtained in a reversible process. Reversible > irreversible work.
Heat Capacity: q = mcΔT (specific heat) Cp − Cv = R (molar); Cp − Cv = R/M (specific) For monoatomic ideal gas: Cv = (3/2)R; Cp = (5/2)R; γ = 5/3 = 1.66 For diatomic gas: γ = 1.40 For triatomic gas: γ = 1.33
Calorimetry:
• Bomb calorimeter → constant volume → measures ΔU
• Coffee-cup calorimeter → constant pressure → measures ΔH
• Joule-Thomson coefficient: \(\mu = (dT/dp)_H\)
• Joule-Thomson inversion temperature: \(T_i = 2a/Rb\)
🔥 Enthalpy & Thermochemistry
H = U + pV (state function, extensive) ΔH = ΔU + ΔngRT where Δng = Σ moles gaseous products − Σ moles gaseous reactants At constant pressure: ΔH = qp ΔH = qp; ΔU = qv; ∴ ΔH = ΔU + pΔV

Thermochemistry Laws
Lavoisier-Laplace Law: ΔH(forward) = −ΔH(reverse) Hess's Law (constant heat summation): ΔH = ΔH₁ + ΔH₂ + ΔH₃ + ... (Independent of path; depends only on initial/final states) Applications: heat of formation, transition, hydration, lattice enthalpy (Born-Haber cycle), bond energies
Trouton's Rule: ΔHvap / Tb ≈ 88 J mol⁻¹ K⁻¹ Kirchhoff's Equation: ΔH₂ − ΔH₁ = ΔCp(T₂ − T₁) Dulong & Petit Law: Specific heat × Molar mass ≈ 6.4 cal/mol/°C (for most metals at 25°C) Clausius-Clapeyron: log(p₂/p₁) = ΔHv/2.303R × (T₂ − T₁)/(T₁T₂)
Bond Enthalpy
For diatomic molecules: unique bond dissociation energy For polyatomic molecules: mean (average) bond enthalpy e.g. O-H bond: ΔH = [(H₂O(g) → 2H(g) + O(g)) / 2] ΔrH° = Σ bond energies of reactants − Σ bond energies of products = Σ (energies of bonds broken) − Σ (energies of bonds formed)
❄️ Entropy & Second Law of Thermodynamics
Entropy S: state function, extensive Units: J K⁻¹ mol⁻¹ ΔS = qrev / T = ΔH / T ΔS > 0: randomness/disorder increases ΔS < 0: randomness/disorder decreases For ideal gas: ΔS = nCv ln(T₂/T₁) + nR ln(V₂/V₁) Standard entropy change: ΔS°rxn = ΣS°(products) − ΣS°(reactants)
Phase transition entropies: ΔSmelting = ΔHfusion / Tm ΔSvap = ΔHvap / Tb (Trouton's: ≈ 88 J mol⁻¹ K⁻¹) ΔSsub = ΔHsub / Tsub Second Law: For a spontaneous process, ΔSuniverse > 0 ΔSsys + ΔSsurr > 0 Third Law (Nernst, 1906): Entropy of a perfectly crystalline substance at 0 K is zero. ΔS = ∫₀ᵀ Cp d(ln T)
Factors that increase entropy (ΔS > 0): gas > liquid > solid; increase in no. of moles of gas; dissolving a solid/liquid in solvent; mixing; higher T.
🟢 Gibbs Energy & Spontaneity
Gibbs energy: G = H − TS (state function, extensive) Gibbs-Helmholtz equation: ΔG = ΔH − TΔS At constant T and P: ΔG < 0 → spontaneous (thermodynamically favourable) ΔG = 0 → at equilibrium ΔG > 0 → non-spontaneous (reverse reaction spontaneous)
Spontaneity Table (ΔG = ΔH − TΔS)
ΔHΔSΔG = ΔH − TΔSSpontaneity
−+Always −Spontaneous at ALL temperatures
+−Always +Non-spontaneous at ALL temperatures
++− at high T (TΔS dominates)Spontaneous only at HIGH temperature
−−− at low T (ΔH dominates)Spontaneous only at LOW temperature
Standard Gibbs energy: ΔG° = ΔH° − TΔS° ΔG° = ΣΔGf°(products) − ΣΔGf°(reactants) ΔGf° of elements in standard state = 0 Relation with equilibrium constant: ΔG° = −RT ln K = −2.303RT log K log K = −ΔG° / (2.303 RT) K = e^(−ΔG°/RT) Relation with cell potential: ΔG° = −nFE°cell
At any condition (reaction quotient Q): ΔG = ΔG° + RT ln Q At equilibrium (Q = K): ΔG = 0; ΔG° = −RT ln K Summary: K >> 1 → ΔG° << 0 (products favoured) K << 1 → ΔG° >> 0 (reactants favoured) K = 1 → ΔG° = 0
🔁 Carnot Cycle
StepProcessWork / Heat
1 → 2Isothermal reversible expansion (at T₂)q₂ absorbed; w₁ = −nRT₂ ln(V₂/V₁)
2 → 3Adiabatic reversible expansionq = 0; work done by gas
3 → 4Isothermal reversible compression (at T₁)q₁ released; w₃ = −nRT₁ ln(V₄/V₃)
4 → 1Adiabatic reversible compressionq = 0; work done on gas
Efficiency (η): η = (T₂ − T₁) / T₂ = w / q₂ T₂ = hot reservoir temperature T₁ = cold reservoir temperature (T₂ > T₁) w = net work done by engine q₂ = heat absorbed from hot source Efficiency = 1 only if T₁ = 0 K (impossible) Maximum efficiency for reversible (Carnot) engine No real engine can be more efficient than Carnot engine
