Mathematical Reasoning

Statements (Propositions)

A statement is an assertive sentence which is either true or false, but not both. Statements are denoted by small letters \(p, q, r, \ldots\)

  • A true statement is a valid statement; a false statement is an invalid statement.
  • Imperative, exclamatory, interrogative, and optative sentences are not statements.
Types of Statements
  • Simple Statement: Cannot be broken into two or more statements. e.g. "\(2\) is a real number."
  • Open Statement: Contains one or more variables; becomes a statement when variables are assigned values. e.g. "\(x > 0\)".
  • Compound Statement: Two or more simple statements combined by logical connectives ('and', 'or', 'if…then', 'if and only if'). The individual parts are called component statements.

Tautology & Contradiction
  • Tautology: A compound statement that is true for every assignment of truth values to its components. e.g. \((p \Rightarrow q) \vee (q \Rightarrow p)\)
  • Contradiction (Fallacy): A compound statement that is false for every assignment. e.g. \(p \wedge \sim p\)
  • Contingency: A statement that is neither a tautology nor a contradiction.

Logically Equivalent Statements

Two compound statements \(S_1\) and \(S_2\) are logically equivalent (written \(S_1 \equiv S_2\)) if they have identical truth tables for all possible truth values.

Converse, Inverse, Contrapositive & Quantifiers

Contrapositive\(\sim q \Rightarrow \sim p\)

Note: A conditional statement and its contrapositive are logically equivalent. A statement and its converse are NOT necessarily equivalent.

  • If \(p\) is true, then \(\sim p\) is false; if \(p\) is false, then \(\sim p\) is true.
  • Number of rows in truth table for \(n\) statements \(= 2^n\).
Quantifiers
  • Universal Quantifier \(\forall\): "for all values of" — used with statements true for every element.
  • Existential Quantifier \(\exists\): "there exists" — used with statements true for at least one element.

An open statement with a quantifier becomes a quantified statement. e.g. \(\forall x \in \mathbb{R}, x^4 \ge 0\) (true).

Negation of quantified statements:

  • \(\sim\{\forall x \in A, p(x) \text{ is true}\} = \exists x \in A \text{ such that } \sim p(x) \text{ is true}\)
  • \(\sim\{\exists x \in A, p(x) \text{ is true}\} = \forall x \in A, \sim p(x) \text{ is true}\)

Validity of Statements

Methods of Checking Validity
  • 'AND' (\(p \wedge q\)): Show that both \(p\) is true and \(q\) is true.
  • 'OR' (\(p \vee q\)): Either (a) assume \(p\) is false, show \(q\) must be true; or (b) assume \(q\) is false, show \(p\) must be true.
  • 'If-then' (\(p \Rightarrow q\)):
    • Direct method: Assume \(p\) is true, show \(q\) must be true.
    • Contrapositive method: Assume \(q\) is false, show \(p\) must be false.
  • 'If and only if' (\(p \Leftrightarrow q\)): Show (i) \(p\) true \(\Rightarrow\) \(q\) true, and (ii) \(q\) true \(\Rightarrow\) \(p\) true.
