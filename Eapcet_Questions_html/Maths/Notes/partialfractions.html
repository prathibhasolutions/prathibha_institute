Partial Fractions

Rational Expressions & Partial Fractions

If \(f(x)\) and \(g(x)\) are polynomials with \(g(x) \ne 0\), then \(\dfrac{f(x)}{g(x)}\) is called a rational expression.

  • Every polynomial is a rational expression, but not vice versa.
  • \(\dfrac{f(x)}{g(x)}\) is in lowest form if \(f(x)\) and \(g(x)\) have no common factor.
  • Proper rational function: \(\deg f < \deg g\).
  • Improper rational function: \(\deg f \ge \deg g\). In this case, perform long division first: \[\frac{f(x)}{g(x)} = \varphi(x) + \frac{h(x)}{g(x)}\] where \(h(x)\) is the remainder with \(\deg h < \deg g\).

Partial fractions decompose a proper rational function \(\dfrac{f(x)}{g(x)}\) into a sum of simpler fractions, each having a simple factor of \(g(x)\) as the denominator.

Partial Fraction Decomposition — All Cases

Case I: Non-repeated Linear Factors

If \(g(x) = (x-a_1)(x-a_2)\cdots(x-a_n)\) with all \(a_i\) distinct:

\[\frac{f(x)}{g(x)} = \frac{A_1}{x-a_1} + \frac{A_2}{x-a_2} + \cdots + \frac{A_n}{x-a_n}\]

Shortcut (Cover-up method): To find \(A_k\), substitute \(x = a_k\) in \(\dfrac{f(x)}{g(x)}\) after cancelling the factor \((x - a_k)\):

\[A_k = \frac{f(a_k)}{(a_k-a_1)\cdots(a_k-a_{k-1})(a_k-a_{k+1})\cdots(a_k-a_n)}\]

Example:

\[\frac{px+q}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}, \quad a \ne b\] \[\frac{px^2+qx+r}{(x-a)(x-b)(x-c)} = \frac{A}{x-a} + \frac{B}{x-b} + \frac{C}{x-c}, \quad a \ne b \ne c\]
Case II: Repeated Linear Factors

If \((x-a)\) is a factor of multiplicity \(k\):

\[\frac{f(x)}{(x-a)^k\cdots} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \cdots + \frac{A_k}{(x-a)^k} + \cdots\]

Examples:

\[\frac{px+q}{(x-a)^2} = \frac{A}{x-a} + \frac{B}{(x-a)^2}\] \[\frac{px^2+qx+r}{(x-a)^3} = \frac{A}{x-a} + \frac{B}{(x-a)^2} + \frac{C}{(x-a)^3}\]

Note: The shortcut (cover-up) applies only to non-repeated factors. Constants for repeated factors must be found by comparing coefficients or substituting convenient values.

Case III: Irreducible Quadratic Factors

If \(g(x)\) contains a quadratic factor \((x^2+bx+c)\) that cannot be factorised over \(\mathbb{R}\):

\[\frac{px^2+qx+r}{(x-a)(x^2+bx+c)} = \frac{A}{x-a} + \frac{Bx+C}{x^2+bx+c}\]

The numerator of the quadratic factor term is linear (\(Bx + C\)), not a constant.

Case IV: Repeated Quadratic Factors

For a quadratic factor \((x^2+bx+c)^2\) (irreducible, repeated):

\[\frac{f(x)}{(x^2+bx+c)^2} = \frac{Ax+B}{x^2+bx+c} + \frac{Cx+D}{(x^2+bx+c)^2}\]
Case V: Two Distinct Irreducible Quadratic Factors
\[\frac{px^3+qx^2+rx+s}{(x^2+ax+b)(x^2+cx+d)} = \frac{Ax+B}{x^2+ax+b} + \frac{Cx+D}{x^2+cx+d}\]

Methods for Finding Unknown Constants

Method 1: Substitution (for Linear Factors)

After clearing denominators, substitute the root of each linear factor to get the constants directly (cover-up rule).

Example: \(\dfrac{2x+3}{(x-1)(x+2)} = \dfrac{A}{x-1}+\dfrac{B}{x+2}\)

Multiply both sides by \((x-1)(x+2)\): \(2x+3 = A(x+2) + B(x-1)\)

Put \(x=1\): \(5 = 3A \Rightarrow A = 5/3\)  |  Put \(x=-2\): \(-1 = -3B \Rightarrow B = 1/3\)

Method 2: Comparing Coefficients

After clearing denominators, expand and equate coefficients of like powers of \(x\) on both sides to get a system of equations, then solve for the unknowns. This works for all cases.

Method 3: Mixed (for Repeated & Quadratic Factors)
  1. Use cover-up rule for all non-repeated linear factors.
  2. Substitute convenient values or compare coefficients for the remaining constants (those corresponding to repeated or quadratic factors).
Properties of Rational Expressions
  • Addition: \(\dfrac{f}{g} + \dfrac{p}{r} = \dfrac{fr + pg}{gr}\)
  • Subtraction: \(\dfrac{f}{g} - \dfrac{p}{r} = \dfrac{fr - pg}{gr}\)
  • Multiplication: \(\dfrac{f}{g} \times \dfrac{p}{r} = \dfrac{fp}{gr}\)
  • Division: \(\dfrac{f}{g} \div \dfrac{p}{r} = \dfrac{f}{g} \times \dfrac{r}{p} = \dfrac{fr}{gp}\)
