Indefinite Integrals

Introduction & Standard Integral Formulae

If \(\dfrac{d}{dx}\{\varphi(x)\} = f(x)\), then \(\displaystyle\int f(x)\,dx = \varphi(x) + C\), where \(C\) is the constant of integration.

  • \(f(x)\) → Integrand  |  \(f(x)\,dx\) → Element of integration  |  \(\varphi(x)\) → Anti-derivative (primitive)
  • The derivative of a function is unique, but the integral is not unique.

Properties of Integration
  • \(\dfrac{d}{dx}\left\{\displaystyle\int f(x)\,dx\right\} = f(x)\)
  • \(\displaystyle\int k\,f(x)\,dx = k\displaystyle\int f(x)\,dx\)
  • \(\displaystyle\int [f_1(x) \pm f_2(x) \pm \cdots \pm f_n(x)]\,dx = \displaystyle\int f_1\,dx \pm \displaystyle\int f_2\,dx \pm \cdots \pm \displaystyle\int f_n\,dx\)

1. Integration by Substitution

For \(\displaystyle\int f\{g(x)\}\cdot g'(x)\,dx\), put \(t = g(x)\) so \(dt = g'(x)\,dx\). Then:

\[\int f\{g(x)\}\cdot g'(x)\,dx = \int f(t)\,dt = F(t) + C = F\{g(x)\} + C\]

Key shortcuts:

  • \(\displaystyle\int \frac{f'(x)}{f(x)}\,dx = \log|f(x)| + C\)
  • \(\displaystyle\int [f(x)]^n \cdot f'(x)\,dx = \dfrac{[f(x)]^{n+1}}{n+1} + C,\quad n \ne -1\)
  • If \(\displaystyle\int f(x)\,dx = \varphi(x) + C\), then \(\displaystyle\int f(ax+b)\,dx = \dfrac{1}{a}\varphi(ax+b) + C\)

Important Forms Converted into Special Integrals

Form I: \(\displaystyle\int \frac{dx}{ax^2+bx+c}\) or \(\displaystyle\int \frac{dx}{\sqrt{ax^2+bx+c}}\)

Express \(ax^2+bx+c = a\!\left[\left(x+\dfrac{b}{2a}\right)^2 + \dfrac{4ac-b^2}{4a^2}\right]\) as sum/difference of squares.

Form II: \(\displaystyle\int \frac{px+q}{ax^2+bx+c}\,dx\) or \(\displaystyle\int \frac{px+q}{\sqrt{ax^2+bx+c}}\,dx\)

Write \(px+q = \lambda \cdot \dfrac{d}{dx}(ax^2+bx+c) + \mu\), find \(\lambda, \mu\), then integrate.

Form III: \(\displaystyle\int \frac{P(x)}{ax^2+bx+c}\,dx\) where \(\deg P \ge 2\)

Perform polynomial long division first to reduce to proper form.

Form IV: \(\displaystyle\int \frac{dx}{a+b\sin^2 x},\ \displaystyle\int \frac{dx}{a+b\cos^2 x},\) etc.

Divide numerator and denominator by \(\cos^2 x\), then put \(t = \tan x \Rightarrow dt = \sec^2 x\,dx\).

Form V: \(\displaystyle\int \frac{dx}{a+b\cos x},\ \displaystyle\int \frac{dx}{a+b\sin x},\) etc.

Put \(\sin x = \dfrac{2\tan(x/2)}{1+\tan^2(x/2)}\), \(\cos x = \dfrac{1-\tan^2(x/2)}{1+\tan^2(x/2)}\), then \(t = \tan\dfrac{x}{2} \Rightarrow dt = \dfrac{1}{2}\sec^2\dfrac{x}{2}\,dx\).

Form VI: \(\displaystyle\int \frac{a\sin x + b\cos x + c}{d\sin x + e\cos x + f}\,dx\)

Write numerator \(= \lambda(\text{denominator}) + \mu(\text{derivative of denominator}) + \gamma\).

Form VII: \(\displaystyle\int \frac{p\sin x + q\cos x + r}{a\sin x + b\cos x + c}\,dx\)

Write \(p\sin x + q\cos x + r = \lambda(a\sin x + b\cos x + c) + \mu(-a\cos x + b\sin x) + \gamma\).

\[\Rightarrow \lambda\!\int dx + \mu\!\int\frac{-a\cos x + b\sin x}{a\sin x+b\cos x+c}\,dx + \gamma\!\int\frac{dx}{a\sin x+b\cos x+c}\]

Form VIII: \(\displaystyle\int \frac{x^2+1}{x^4+\lambda x^2+1}\,dx\), \(\displaystyle\int \frac{x^2-1}{x^4+\lambda x^2+1}\,dx\), etc.

Divide by \(x^2\), write denominator as \(\left(x \mp \dfrac{1}{x}\right)^2 \pm k\), introduce \(d\!\left(x \pm \dfrac{1}{x}\right)\).

Form IX: \(\displaystyle\int\sqrt{\tan x}\,dx\), \(\displaystyle\int\sqrt{\cot x}\,dx\), etc.

Put \(\tan x = t^2\), then proceed as Form VIII.

2. Integration by Parts

Used to integrate the product of two functions:

\[\int \underbrace{f(x)}_{\text{I}} \cdot \underbrace{g(x)}_{\text{II}}\,dx = f(x)\int g(x)\,dx - \int\left[\frac{d}{dx}f(x)\cdot\int g(x)\,dx\right]dx\]
ILATE Rule — Order of Priority for First Function

Choose the first function according to priority:

I — Inverse trig → L — Logarithmic → A — Algebraic → T — Trigonometric → E — Exponential
  • If one function is not directly integrable, take it as the first function.
  • If only one function is present (e.g. \(\int\log x\,dx\)), take \(1\) as the second function.
  • If both are integrable, choose the one whose derivative simplifies faster as the first function.
Integral of \(e^x[f(x) + f'(x)]\)
\[\int e^x\{f(x) + f'(x)\}\,dx = e^x f(x) + C\]

Similarly: \(\displaystyle\int \{xf'(x) + f(x)\}\,dx = xf(x) + C\)

Integrals of \(e^{ax}\sin(bx+c)\) and \(e^{ax}\cos(bx+c)\)
\[\int e^{ax}\sin(bx+c)\,dx = \frac{e^{ax}}{a^2+b^2}\{a\sin(bx+c) - b\cos(bx+c)\} + k\] \[\int e^{ax}\cos(bx+c)\,dx = \frac{e^{ax}}{a^2+b^2}\{a\cos(bx+c) + b\sin(bx+c)\} + k\]

3. Integration by Partial Fractions

Used to integrate \(\displaystyle\int\dfrac{P(x)}{Q(x)}\,dx\) where \(P(x)\) and \(Q(x)\) are polynomials.

  • Proper rational function: \(\deg P < \deg Q\).
  • Improper rational function: \(\deg P \ge \deg Q\) → perform long division first to get \(\dfrac{P(x)}{Q(x)} = \varphi(x) + \dfrac{h(x)}{Q(x)}\).

Important Results of Integration

Key Results
  • Anti-derivative of signum function exists only on intervals not containing \(x = 0\).
  • Anti-derivative of an odd function is always even; of an even function is always odd.
  • Reduction formula: If \(I_n = \displaystyle\int x^n e^{ax}\,dx\), then \(I_n = \dfrac{x^n e^{ax}}{a} - \dfrac{n}{a}I_{n-1}\)
  • \(\displaystyle\int \log x\,dx = x\log x - x + C\)
  • \(\displaystyle\int \frac{1}{\log x}\,dx = x\log(\log x) + \frac{x}{\log x} + \frac{x^2}{2(\log x)^2\cdot 2!} + \frac{x^3}{3(\log x)^3\cdot 3!} + \cdots\)
\(\displaystyle\int\frac{a\cos x + b\sin x}{c\cos x + d\sin x}\,dx\)
\[\int\frac{a\cos x+b\sin x}{c\cos x+d\sin x}\,dx = \frac{ac+bd}{c^2+d^2}\,x + \frac{bc-ad}{c^2+d^2}\log|c\cos x + d\sin x| + k\]
Reduction Formula for \(\displaystyle\int\sin^m x\cos^n x\,dx\)
\[\int\sin^n x\cos^m x\,dx = \frac{\sin^{n-1}x\cos^{m+1}x}{n+m-1} \cdot \frac{1}{-(m+1)} + \cdots\]

Specifically:

  • \(\displaystyle\int\sin^n x\,dx = -\dfrac{1}{n}\sin^{n-1}x\cos x + \dfrac{n-1}{n}\displaystyle\int\sin^{n-2}x\,dx\)
  • \(\displaystyle\int\cos^n x\,dx = \dfrac{1}{n}\cos^{n-1}x\sin x + \dfrac{n-1}{n}\displaystyle\int\cos^{n-2}x\,dx\)
  • \(\displaystyle\int\tan^n x\,dx = \dfrac{\tan^{n-1}x}{n-1} - \displaystyle\int\tan^{n-2}x\,dx\)
Integrals of \(a^x\sin(bx+c)\) and \(a^x\cos(bx+c)\)
\[\int a^x\cos(bx+c)\,dx = \frac{a^x}{(\log a)^2+b^2}\left[(\log a)\cos(bx+c) + b\sin(bx+c)\right] + k\] \[\int a^x\sin(bx+c)\,dx = \frac{a^x}{(\log a)^2+b^2}\left[(\log a)\sin(bx+c) - b\cos(bx+c)\right] + k\]
Integrals of \(xe^{ax}\sin(bx+c)\) and \(xe^{ax}\cos(bx+c)\)
\[\begin{aligned} \int xe^{ax}\cos(bx+c)\,dx &= \frac{xe^{ax}}{a^2+b^2}\Big[a\cos(bx+c)+b\sin(bx+c)\Big]\\ &\quad - \frac{e^{ax}}{(a^2+b^2)^2}\Big[(a^2-b^2)\cos(bx+c)+2ab\sin(bx+c)\Big] + k \end{aligned}\] \[\begin{aligned} \int xe^{ax}\sin(bx+c)\,dx &= \frac{xe^{ax}}{a^2+b^2}\Big[a\sin(bx+c)-b\cos(bx+c)\Big]\\ &\quad - \frac{e^{ax}}{(a^2+b^2)^2}\Big[(a^2-b^2)\sin(bx+c)-2ab\cos(bx+c)\Big] + k \end{aligned}\]
