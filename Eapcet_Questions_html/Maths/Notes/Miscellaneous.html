Polynomials — Operations & Key Theorems

A polynomial \(f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0\) with \(a_n \ne 0\) has degree \(n\).

Operations on Polynomials
  • Division Algorithm: \(p(x) = q(x)\cdot g(x) + r(x)\), where \(\deg r < \deg g\).
  • Synthetic Division (Horner's Method): For dividing by \((x - h)\): write coefficients of \(f(x)\), carry \(b_0 = a_0\) and compute each \(b_{k+1} = a_{k+1} + h\cdot b_k\). The last value is the remainder \(R\).
Remainder & Factor Theorems
  • Remainder Theorem: When \(p(x)\) is divided by \((x-a)\), the remainder is \(p(a)\).
  • Factor Theorem: \((x-a)\) is a factor of \(p(x)\) iff \(p(a) = 0\).
  • If \(p(x)\) is divided by \((ax-b)\), remainder is \(p(b/a)\).
  • If \(p(x)\) is divided by \((ax+b)\), remainder is \(p(-b/a)\).

HCF & LCM of Polynomials
  • \(\text{LCM} = \dfrac{\text{Product of polynomials}}{\text{HCF}}\)
  • \(\text{HCF} = \dfrac{\text{Product of polynomials}}{\text{LCM}}\)
  • For any two polynomials \(p(x)\) and \(q(x)\): \(p(x) \times q(x) = \text{HCF} \times \text{LCM}\)

Important Factorisation Identities

Standard Algebraic Identities
  • \((x+a)^2 = x^2 + 2xa + a^2\)
  • \((x-a)^2 = x^2 - 2xa + a^2\)
  • \((x+a)^3 = x^3 + 3x^2a + 3xa^2 + a^3\)
  • \((x-a)^3 = x^3 - 3x^2a + 3xa^2 - a^3\)
  • \(a^3+b^3+c^3-3abc = (a+b+c)(a^2+b^2+c^2-ab-bc-ca)\)
  • If \(a+b+c=0\): \(a^3+b^3+c^3 = 3abc\)
  • \((x-a)(x^2+ax+a^2) = x^3-a^3\)
  • \((x+a)(x^2-ax+a^2) = x^3+a^3\)
  • For even \(n\): \((x+a)(x^{n-1}-x^{n-2}a+\cdots-a^{n-1}) = x^n - a^n\)
  • For odd \(n\): \((x+a)(x^{n-1}-x^{n-2}a+\cdots+a^{n-1}) = x^n + a^n\)
  • \((x^2+xy+y^2)(x^2-xy+y^2) = x^4+x^2y^2+y^4\)
Reciprocal Identities
  • \(x^2 + \dfrac{1}{x^2} = \left(x+\dfrac{1}{x}\right)^2 - 2 = \left(x-\dfrac{1}{x}\right)^2 + 2\)
  • \(x^3 + \dfrac{1}{x^3} = \left(x+\dfrac{1}{x}\right)^3 - 3\left(x+\dfrac{1}{x}\right)\)
  • \(x^3 - \dfrac{1}{x^3} = \left(x-\dfrac{1}{x}\right)^3 + 3\left(x-\dfrac{1}{x}\right)\)
  • \(\left(x+\dfrac{1}{x}\right)^2 + \left(x-\dfrac{1}{x}\right)^2 = 2\left(x^2+\dfrac{1}{x^2}\right)\)

Linear Equations & Simultaneous Equations

Solving Simultaneous Linear Equations in Two Variables

For system \(a_1x + b_1y + c_1 = 0\) and \(a_2x + b_2y + c_2 = 0\):

Cross-multiplication method:

\[\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}\]

Consistency conditions:

ConditionNature of Solution
\(\dfrac{a_1}{a_2} \ne \dfrac{b_1}{b_2}\)Unique solution (consistent)
\(\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \ne \dfrac{c_1}{c_2}\)No solution (inconsistent)
\(\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}\)Infinitely many solutions

Other methods: Substitution, Elimination by equating coefficients, Graphical method.

Logarithms

If \(a^x = m\) where \(a > 0, a \ne 1, m > 0\), then \(x = \log_a m\).

  • If \(m \le 0\): \(\log_a m\) is not defined.
  • \(\log_a m\) exists only if \(m > 0, a > 0, a \ne 1\).
Types of Logarithms
  • Natural (Napier) Logarithm: Base \(e \approx 2.718\). Written as \(\ln x\) or \(\log_e x\).
  • Common (Brigg's) Logarithm: Base 10. Written as \(\log_{10} x\) or simply \(\log x\).
Characteristic & Mantissa

Every logarithm consists of two parts: characteristic (integer part) and mantissa (decimal part, always \(\ge 0\)).

  • For \(x > 1\): characteristic \(=\) (number of digits before decimal) \(-1\).
  • For \(0 < x < 1\): characteristic is negative \(= -(n+1)\) where \(n\) = zeros after decimal before first significant digit.
  • Bar notation: \(\bar{2}\) means \(-2\) (only the characteristic is negative; mantissa remains positive).
  • Numbers with the same sequence of significant digits have the same mantissa, regardless of the decimal point position.
Laws of Logarithms
LawFormulaCondition
Product\(\log_a(mn) = \log_a m + \log_a n\)\(m,n,a>0,\,a\ne1\)

Reciprocal base\(\log_{1/a} m = -\log_a m\)

  • \(\log_a b = \dfrac{1}{\log_b a}\)
  • \(\log_a b \cdot \log_b c \cdot \log_c d = \log_a d\) (chain rule)
  • If \(\log_a x = \log_b x\) and \(x \ne 1\), then \(a = b\).
  • If \(\log_a x = \log_a y\), then \(x = y\).
Antilogarithm & Key Results

\(a = \text{antilog}(b) \Leftrightarrow \log a = b \Leftrightarrow 10^b = a\).

  • If \(a > 1\): \(\log_a x > 0\) for \(x > 1\); \(\log_a x < 0\) for \(0 < x < 1\).
  • If \(0 < a < 1\): \(\log_a x < 0\) for \(x > 1\); \(\log_a x > 0\) for \(0 < x < 1\).
  • \(\log_a x = \log_a y \Rightarrow x = y\).
  • \(\log_a x > \log_a y \Rightarrow x > y\) if \(a > 1\); \(x < y\) if \(0 < a < 1\).
