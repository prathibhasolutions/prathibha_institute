Theory of Equations & Quadratic Expressions

Polynomials & Quadratic Equations

A polynomial \(f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0\) has degree \(n\) if \(a_n \ne 0\). Types: Linear (degree 1), Quadratic (degree 2), Cubic (degree 3), Biquadratic (degree 4).

Quadratic Equation \(ax^2+bx+c=0\)

Roots by Sridharacharya formula: \(\alpha, \beta = \dfrac{-b \pm \sqrt{D}}{2a}\), where \(D = b^2 - 4ac\).

Discriminant \(D\)Nature of Roots
\(D < 0\)Complex (non-real) conjugate roots
\(D > 0\)Real and distinct
\(D = 0\)Real and equal: \(\alpha = \beta = -b/2a\)
\(D > 0\), perfect square, \(a,b,c \in \mathbb{Q}\)Rational and unequal
\(D > 0\), not perfect square, \(a,b,c \in \mathbb{Q}\)Irrational and unequal (conjugate surds)

Conjugate roots: If \(a,b,c \in \mathbb{R}\): irrational roots occur as \(\alpha+\sqrt{\beta}\) and \(\alpha-\sqrt{\beta}\). If \(a,b,c \in \mathbb{R}\): complex roots occur as \(\alpha+i\beta\) and \(\alpha-i\beta\).

Roots under Particular Conditions
  • \(b = 0\): roots are equal in magnitude, opposite sign.
  • \(c = 0\): one root is 0, other is \(-b/a\).
  • \(b = c = 0\): both roots are 0.
  • \(a = c\): roots are reciprocals of each other.
  • \(a > 0, c < 0\) (or \(a < 0, c > 0\)): roots are of opposite sign.
  • \(a, b, c\) same sign with \(D \ge 0\): both roots negative.
  • \(a, c\) same sign, \(b\) opposite with \(D \ge 0\): both roots positive.
  • \(\text{sign}(a) = \text{sign}(b) \ne \text{sign}(c)\): greater root in magnitude is negative.
  • \(\text{sign}(b) = \text{sign}(c) \ne \text{sign}(a)\): greater root in magnitude is positive.
  • \(a + b + c = 0\): one root is 1, other is \(c/a\).

Relations between Roots & Coefficients

Quadratic: \(ax^2+bx+c=0\)
\[\alpha+\beta = -\frac{b}{a}, \quad \alpha\beta = \frac{c}{a}, \quad |\alpha-\beta| = \frac{\sqrt{D}}{|a|}\]

Equation from roots: \(x^2 - (\alpha+\beta)x + \alpha\beta = 0\)

Cubic: \(ax^3+bx^2+cx+d=0\)
\[\alpha+\beta+\gamma = -\frac{b}{a}, \quad \alpha\beta+\beta\gamma+\gamma\alpha = \frac{c}{a}, \quad \alpha\beta\gamma = -\frac{d}{a}\]
Biquadratic: \(ax^4+bx^3+cx^2+dx+e=0\)
\[S_1 = \alpha+\beta+\gamma+\delta = -\frac{b}{a}\] \[S_2 = \sum\alpha\beta = \frac{c}{a}\] \[S_3 = \sum\alpha\beta\gamma = -\frac{d}{a}\] \[S_4 = \alpha\beta\gamma\delta = \frac{e}{a}\]

ExpressionValue

Quadratic Expression \(ax^2+bx+c\)

The graph of \(y = ax^2+bx+c\) is a parabola with vertex at \(\left(-\dfrac{b}{2a},\,-\dfrac{D}{4a}\right)\).

Sign of Quadratic Expression
ConditionSign of \(f(x)\)
\(a > 0,\; D < 0\)\(f(x) > 0\) for all \(x \in \mathbb{R}\)
\(a < 0,\; D < 0\)\(f(x) < 0\) for all \(x \in \mathbb{R}\)
\(a > 0,\; D = 0\)\(f(x) \ge 0\) for all \(x\) (= 0 at vertex)
\(a < 0,\; D = 0\)\(f(x) \le 0\) for all \(x\) (= 0 at vertex)
\(a > 0,\; D > 0\), roots \(\alpha < \beta\)\(f(x) > 0\) for \(x < \alpha\) or \(x > \beta\); \(f(x) < 0\) for \(x \in (\alpha,\beta)\)
\(a < 0,\; D > 0\), roots \(\alpha < \beta\)\(f(x) < 0\) for \(x < \alpha\) or \(x > \beta\); \(f(x) > 0\) for \(x \in (\alpha,\beta)\)
Max & Min Values
  • If \(a > 0\): minimum value \(= -\dfrac{D}{4a}\) at \(x = -\dfrac{b}{2a}\). No maximum.
  • If \(a < 0\): maximum value \(= -\dfrac{D}{4a}\) at \(x = -\dfrac{b}{2a}\). No minimum.
Position of Roots in an Interval

For \(f(x) = ax^2+bx+c\), let \(D = b^2-4ac\) and vertex \(x_v = -b/2a\):

  • Both roots \(> k\): \(D \ge 0\), \(x_v > k\), and \(af(k) > 0\)
  • Both roots \(< k\): \(D \ge 0\), \(x_v < k\), and \(af(k) > 0\)
  • Both roots in \((k_1, k_2)\): \(D \ge 0\), \(k_1 < x_v < k_2\), \(af(k_1) > 0\), \(af(k_2) > 0\)
  • Exactly one root in \((k_1, k_2)\): \(D > 0\) and \(f(k_1)\cdot f(k_2) < 0\)
  • \(k\) lies between the roots: \(D > 0\) and \(af(k) < 0\)
  • Roots of opposite sign: \(f(0) < 0\), i.e. \(c/a < 0\)

Common Roots, Properties & Transformations

Condition for Common Roots

For \(a_1x^2+b_1x+c_1=0\) and \(a_2x^2+b_2x+c_2=0\):

  • Exactly one common root (by Cramer's rule): \[(c_1a_2-c_2a_1)^2 = (b_1c_2-b_2c_1)(a_1b_2-a_2b_1)\]
  • Both roots common: \(\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}\)

Trick to find common root: Make coefficients of \(x^2\) equal and subtract.

Transformation of Roots

If \(\alpha, \beta\) are roots of \(ax^2+bx+c=0\), then the equation with roots:

  • \(-\alpha, -\beta\): replace \(x\) by \(-x\) → \(ax^2-bx+c=0\)
  • \(\alpha^n, \beta^n\): replace \(x\) by \(x^{1/n}\) → \(a(x^{1/n})^2+b(x^{1/n})+c=0\)
  • \(k\alpha, k\beta\): replace \(x\) by \(x/k\) → \(ax^2+kbx+k^2c=0\)
  • \(k+\alpha, k+\beta\): replace \(x\) by \((x-k)\) → \(a(x-k)^2+b(x-k)+c=0\)
  • \(1/\alpha, 1/\beta\): replace \(x\) by \(1/x\) → \(cx^2+bx+a=0\)
  • \(k/\alpha, k/\beta\): replace \(x\) by \(kx\) → \(ax^2+kbx+k^2c=0\) (then flip)
Properties of Polynomial Equations
  • An equation of degree \(n\) has exactly \(n\) roots (real or complex).
  • Irrational roots of polynomial with rational coefficients occur in conjugate pairs: if \(p+\sqrt{q}\) is a root, so is \(p-\sqrt{q}\).
  • Complex roots of polynomial with real coefficients occur in conjugate pairs: if \(a+ib\) is a root, so is \(a-ib\).
  • If \(f(a)\cdot f(b) < 0\): odd number of roots lie between \(a\) and \(b\).
  • If \(f(a)\cdot f(b) > 0\): even number of roots (or none) between \(a\) and \(b\).
  • \(\alpha\) is a repeated root of multiplicity \(n\) iff \(f(\alpha) = f'(\alpha) = \cdots = f^{(n-1)}(\alpha) = 0\) and \(f^{(n)}(\alpha) \ne 0\).
  • An odd degree equation has at least one real root with sign opposite to its constant term.
  • Every even degree equation with negative constant term and positive leading coefficient has at least two real roots (one positive, one negative).
Descartes' Rule & Lagrange's Identity

Descartes' Rule: Maximum number of positive real roots of \(f(x)=0\) = number of sign changes in \(f(x)\). Maximum number of negative real roots = number of sign changes in \(f(-x)\).

Lagrange's Identity: For \(a_1,a_2,a_3,b_1,b_2,b_3 \in \mathbb{R}\):

\[(a_1^2+a_2^2+a_3^2)(b_1^2+b_2^2+b_3^2) = (a_1b_1+a_2b_2+a_3b_3)^2 + (a_1b_2-a_2b_1)^2 + (a_2b_3-a_3b_2)^2 + (a_3b_1-a_1b_3)^2\]

Inequalities

An inequality is a statement involving \(>, <, \le, \ge\).

Properties & Rules
  • Adding or subtracting the same number from both sides preserves the inequality.
  • Multiplying/dividing by a positive number preserves the inequality.
  • Multiplying/dividing by a negative number reverses the inequality.
  • If \(a > b > 0\): \(a^2 > b^2\), \(|a| > |b|\), \(1/a < 1/b\).
  • Transitivity: \(a > b, b > c \Rightarrow a > c\).
Absolute Value Inequalities
  • \(|x| < a \Leftrightarrow -a < x < a\)  \((a > 0)\)
  • \(|x| \le a \Leftrightarrow -a \le x \le a\)
  • \(|x| > a \Leftrightarrow x < -a\) or \(x > a\)
  • \(|x| \ge a \Leftrightarrow x \le -a\) or \(x \ge a\)
AM–GM–HM Inequalities

For positive reals \(a_1, a_2, \ldots, a_n\):

\[\text{AM} \ge \text{GM} \ge \text{HM}\] \[\frac{a_1+a_2+\cdots+a_n}{n} \ge (a_1 a_2 \cdots a_n)^{1/n} \ge \frac{n}{\frac{1}{a_1}+\frac{1}{a_2}+\cdots+\frac{1}{a_n}}\]

Weighted AM-GM: \(\dfrac{m_1a_1+m_2a_2+\cdots}{m_1+m_2+\cdots} \ge a_1^{m_1/(m_1+m_2+\cdots)}\cdot a_2^{m_2/(\cdots)}\cdots\)

Equality holds iff all values are equal.

Finding Range of Rational Expressions

To find values of \(\dfrac{a_1x^2+b_1x+c_1}{a_2x^2+b_2x+c_2}\) for real \(x\):

  1. Set the expression equal to \(y\).
  2. Rearrange to get a quadratic in \(x\).
  3. For real \(x\), discriminant \(\ge 0\).
  4. Solve the resulting inequality for \(y\).
