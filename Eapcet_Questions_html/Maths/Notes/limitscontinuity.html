Limits, Continuity & Differentiability

Limits

If \(f(x)\) takes an indeterminate form at \(x = a\) \(\left(\dfrac{0}{0},\,\dfrac{\infty}{\infty},\,0\times\infty,\,\infty-\infty,\,1^\infty,\,0^0,\,\infty^0\right)\), we consider values near \(a\). If these tend to a unique number, that number is the limit:

\[\lim_{x \to a} f(x) = L\]
Left Hand & Right Hand Limits; Existence
  • LHL: \(\displaystyle\lim_{x \to a^-} f(x) = \lim_{h \to 0} f(a-h)\)
  • RHL: \(\displaystyle\lim_{x \to a^+} f(x) = \lim_{h \to 0} f(a+h)\)
  • \(\lim_{x\to a} f(x)\) exists iff LHL and RHL both exist and are equal.
  • If the limit exists, it is unique.
Fundamental Theorems on Limits

If \(\lim_{x\to a}f(x)\) and \(\lim_{x\to a}g(x)\) both exist:

  • \(\lim[f \pm g] = \lim f \pm \lim g\)
  • \(\lim[kf] = k\lim f\)
  • \(\lim[fg] = \lim f \cdot \lim g\)
  • \(\lim\dfrac{f}{g} = \dfrac{\lim f}{\lim g}\) (provided \(\lim g \ne 0\))
  • \(\lim[f(x)]^{g(x)} = \left[\lim f(x)\right]^{\lim g(x)}\)
  • \(\lim(g \circ f)(x) = g\!\left(\lim_{x\to a} f(x)\right)\)
  • \(\lim \log f(x) = \log\!\left(\lim f(x)\right)\) provided \(\lim f(x) > 0\)
  • If \(f(x) \le g(x)\) near \(a\), then \(\lim f \le \lim g\)
  • If \(\lim f(x) = +\infty\) or \(-\infty\), then \(\lim\dfrac{1}{f(x)} = 0\)
Standard Limits

Algebraic:

  • \(\displaystyle\lim_{x\to a}\frac{x^n - a^n}{x - a} = na^{n-1},\quad n \in \mathbb{Q}\)
  • \(\displaystyle\lim_{x\to 0}\frac{(1+x)^n - 1}{x} = n,\quad n \in \mathbb{Q}\)

Trigonometric:

  • \(\displaystyle\lim_{x\to 0}\frac{\sin x}{x} = 1\), \(\quad\lim_{x\to 0}\frac{\tan x}{x} = 1\), \(\quad\lim_{x\to 0}\frac{\sin^{-1}x}{x} = 1\), \(\quad\lim_{x\to 0}\frac{\tan^{-1}x}{x} = 1\)
  • \(\displaystyle\lim_{x\to 0}\cos x = 1\), \(\quad\lim_{x\to 0}\frac{1-\cos x}{x^2} = \frac{1}{2}\)
  • \(\displaystyle\lim_{x\to a}\frac{\sin(x-a)}{x-a} = 1\), \(\quad\lim_{x\to a}\frac{\tan(x-a)}{x-a} = 1\)
  • \(\displaystyle\lim_{x\to 0}\frac{\sin mx}{\sin nx} = \frac{m}{n}\), \(\quad\lim_{x\to 0}\frac{\tan(ax)}{\tan(bx)} = \frac{a}{b}\)
  • \(\displaystyle\lim_{x\to\infty}\frac{\sin x}{x} = 0\), \(\quad\lim_{x\to\infty}\frac{\cos x}{x} = 0\)
  • \(\displaystyle\lim_{x\to 0}\frac{\sin x°}{x} = \frac{\pi}{180}\)
  • \(\displaystyle\lim_{x\to 0}\frac{\cos mx - \cos nx}{x^2} = \frac{n^2 - m^2}{2}\)
  • \(\displaystyle\lim_{x\to 0}\frac{1 - \cos ax}{1 - \cos bx} = \frac{a^2}{b^2}\)
  • \(\displaystyle\lim_{x\to\infty}\cos\frac{x}{2}\cos\frac{x}{4}\cos\frac{x}{8}\cdots = \frac{\sin x}{x}\)

Exponential:

  • \(\displaystyle\lim_{x\to 0}\frac{e^x - 1}{x} = 1\), \(\quad\lim_{x\to 0}\frac{a^x - 1}{x} = \log_e a\), \(\quad\lim_{x\to 0}\frac{e^{\lambda x}-1}{x} = \lambda\)
  • \(\displaystyle\lim_{x\to\infty}a^x = \begin{cases}0 & 0 < a < 1\\ 1 & a = 1\\ \infty & a > 1\end{cases}\)
  • \(\displaystyle\lim_{x\to\infty}\frac{x^n}{e^x} = 0\) for all \(n\)

Logarithmic:

  • \(\displaystyle\lim_{x\to 0}\frac{\log_e(1+x)}{x} = 1\), \(\quad\lim_{x\to 0}\frac{\log_e(1-x)}{x} = -1\)
  • \(\displaystyle\lim_{x\to e}\log_e x = 1\), \(\quad\lim_{x\to 0}\frac{\log_a(1+x)}{x} = \log_a e\)

Form \(1^\infty\):

  • \(\displaystyle\lim_{x\to 0}(1+x)^{1/x} = e\), \(\quad\lim_{x\to\infty}\left(1+\frac{1}{x}\right)^x = e\)
  • \(\displaystyle\lim_{x\to 0}(1+\lambda x)^{1/x} = e^\lambda\), \(\quad\lim_{x\to\infty}\left(1+\frac{\lambda}{x}\right)^x = e^\lambda\)
  • If \(\lim f(x) = 1\) and \(\lim g(x) = \infty\): \(\lim [f(x)]^{g(x)} = e^{\lim[f(x)-1]g(x)}\)
  • \(\displaystyle\lim_{x\to 0}(\cos x + a\sin bx)^{1/x} = e^{ab}\)
  • \(\displaystyle\lim_{n\to\infty}(x^n + y^n)^{1/n} = y\) for \(0 < x < y\)
Methods of Evaluating Limits
  • Direct substitution: Substitute \(x = a\) if result is definite.
  • Factorisation: For \(0/0\) form — cancel common factor \((x-a)\).
  • Rationalisation: For \(0/0\) or \(\infty/\infty\) involving square roots.
  • Substitution: Put \(x = a+h\) so \(h \to 0\).
  • When \(x \to \infty\): Divide numerator and denominator by highest power of \(x\). If degrees are \(m\) and \(n\): \[\lim_{x\to\infty}\frac{a_0x^m + \cdots}{b_0x^n + \cdots} = \begin{cases}a_0/b_0 & m = n\\ 0 & m < n\\ \pm\infty & m > n\end{cases}\]
  • L'Hospital's Rule: If \(\lim f(a) = \lim g(a) = 0\) (or \(\infty\)) and both are differentiable: \[\lim_{x\to a}\frac{f(x)}{g(x)} = \lim_{x\to a}\frac{f'(x)}{g'(x)}\] Apply repeatedly if needed.
Standard Expansions for Limits
  • \((1+x)^n = 1 + nx + \dfrac{n(n-1)}{2!}x^2 + \cdots\)  \((|x| < 1, n \in \mathbb{Q})\)
  • \(e^x = 1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!} + \cdots\)
  • \(\log_e(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots\)  \((-1 < x \le 1)\)
  • \(\sin x = x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \cdots\)
  • \(\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots\)
  • \(\tan x = x + \dfrac{x^3}{3} + \dfrac{2x^5}{15} + \cdots\)
  • \(\sin^{-1}x = x + \dfrac{x^3}{6} + \dfrac{3x^5}{40} + \cdots\)
  • \(\tan^{-1}x = x - \dfrac{x^3}{3} + \dfrac{x^5}{5} - \cdots\)
Sandwich (Squeeze) Theorem

If \(f(x) \le g(x) \le h(x)\) for all \(x\) near \(a\), and \(\displaystyle\lim_{x\to a}f(x) = \lim_{x\to a}h(x) = l\), then:

\[\lim_{x\to a}g(x) = l\]

Continuity

A function \(f\) is continuous at \(x = a\) if:

\[\lim_{x\to a^-}f(x) = \lim_{x\to a^+}f(x) = f(a)\]
Discontinuity

\(f\) is discontinuous at \(x = a\) if any of:

  • \(f(a)\) is not defined.
  • LHL ≠ RHL (both finite).
  • LHL or RHL does not exist or is infinite.
  • LHL = RHL ≠ \(f(a)\).

Types of discontinuity:

  • Removable: \(\lim_{x\to a}f(x)\) exists but \(\ne f(a)\) (or \(f(a)\) undefined). Can be fixed by redefining \(f(a)\).
  • Jump (1st kind): LHL and RHL both exist but LHL ≠ RHL. Jump \(= |\text{LHL} - \text{RHL}|\).
  • 2nd kind: At least one of LHL or RHL does not exist or is infinite.
Theorems of Continuity
  • If \(f\) and \(g\) are continuous, so are \(f \pm g\), \(fg\), \(cf\), and \(\dfrac{f}{g}\) (where \(g \ne 0\)).
  • If \(g\) is continuous at \(a\) and \(f\) is continuous at \(g(a)\), then \(f \circ g\) is continuous at \(a\).
  • If \(f\) is continuous on \([a,b]\), it is bounded on \([a,b]\).
  • If \(f\) is continuous on \([a,b]\) and \(f(a)\cdot f(b) < 0\), then \(f(c) = 0\) for some \(c \in (a,b)\). (Intermediate Value Theorem)
  • If \(f\) is continuous on \([a,b]\), then \(|f|\) is also continuous.

Differentiability

\(f(x)\) is differentiable at \(x = a\) if:

\[\lim_{x\to a}\frac{f(x)-f(a)}{x-a} \text{ exists finitely, i.e. } Lf'(a) = Rf'(a)\]

where \(Lf'(a) = \lim_{x\to a^-}\dfrac{f(x)-f(a)}{x-a}\) (LHD) and \(Rf'(a) = \lim_{x\to a^+}\dfrac{f(x)-f(a)}{x-a}\) (RHD).

Geometrically, \(f\) is differentiable at \(P\) iff the curve has a unique tangent at \(P\) (no corners, holes, cusps, or vertical tangents).

Key Theorems on Differentiability
  • Sum, difference, product, quotient (when defined) of differentiable functions are differentiable.
  • Composition of differentiable functions is differentiable.
  • If \(f\) and \(g\) are both non-differentiable, their sum or product may still be differentiable.
Relation between Continuity and Differentiability
  • Differentiable \(\Rightarrow\) Continuous (converse is NOT true).
  • Not continuous \(\Rightarrow\) Not differentiable.
  • A function can be continuous but not differentiable (e.g. \(f(x) = |x|\) at \(x=0\)).
