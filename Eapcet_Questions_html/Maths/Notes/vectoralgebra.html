Vector Algebra

Introduction & Types of Vectors

A vector has both direction and magnitude, whereas a scalar has only magnitude.

e.g. Vector quantities: displacement, velocity, acceleration. Scalar quantities: length, mass, time.

Characteristics of a Vector
  • Magnitude: The length \(|\overrightarrow{AB}|\) or \(|\mathbf{a}|\) of the vector.
  • Sense: The direction from initial point to terminal point. Sense of \(\overrightarrow{AB}\) is from \(A\) to \(B\).
  • Support: The line of infinite length of which the line segment \(\overrightarrow{AB}\) is a part.
Types of Vectors
  • Zero (Null) Vector: Initial and terminal points coincide. Denoted by \(\mathbf{0}\).
  • Unit Vector: Magnitude = 1. Unit vector in direction of \(\mathbf{n}\) is \(\hat{n} = \dfrac{\mathbf{n}}{|\mathbf{n}|}\).
  • Free Vector: Initial point is not specified.
  • Like & Unlike Vectors: Like — same direction; Unlike — opposite directions.
  • Collinear (Parallel) Vectors: Have the same or parallel supports.
  • Equal Vectors: Same length and same direction. \(\mathbf{a} = \mathbf{b}\).
  • Negative Vector: Same magnitude as \(\mathbf{a}\) but opposite direction: \(-\mathbf{a}\).
  • Coinitial Vectors: Same initial point.
  • Coterminus Vectors: Same terminal point.
  • Localised Vector: Drawn parallel to a given vector through a specified point in space.
  • Coplanar Vectors: Supports are parallel to the same plane.
  • Reciprocal of a Vector: Same direction as \(\mathbf{a}\) but magnitude \(\dfrac{1}{|\mathbf{a}|}\). Denoted \(\mathbf{a}^{-1}\).

Addition & Subtraction of Vectors

Triangle Law of Vector Addition

From the terminal point of \(\mathbf{a}\), draw \(\mathbf{b}\). Then the vector from the initial point of \(\mathbf{a}\) to the terminal point of \(\mathbf{b}\) is \(\mathbf{a} + \mathbf{b}\).

Note: When sides of a triangle are taken in order: \(\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CA} = \mathbf{0}\)

Parallelogram Law of Vector Addition

From the same initial point, draw \(\mathbf{a}\) and \(\mathbf{b}\) as adjacent sides of a parallelogram. The diagonal through the common vertex represents \(\mathbf{a} + \mathbf{b}\).

The bisector of the angle between non-collinear vectors \(\mathbf{a}\) and \(\mathbf{b}\) is \(\lambda(\hat{a} + \hat{b})\) or \(\lambda\!\left(\dfrac{\mathbf{a}}{|\mathbf{a}|} \pm \dfrac{\mathbf{b}}{|\mathbf{b}|}\right)\).

Properties of Vector Addition
  • Commutative: \(\mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}\)
  • Associative: \((\mathbf{a} + \mathbf{b}) + \mathbf{c} = \mathbf{a} + (\mathbf{b} + \mathbf{c})\)
  • Additive Identity: \(\mathbf{a} + \mathbf{0} = \mathbf{a}\)
  • Additive Inverse: \(\mathbf{a} + (-\mathbf{a}) = \mathbf{0}\)
Subtraction of Vectors

The difference \(\mathbf{a} - \mathbf{b} = \mathbf{a} + (-\mathbf{b})\).

Multiplication by a Scalar & Components

Multiplication of a Vector by a Scalar

For scalar \(\lambda\) and vector \(\mathbf{a}\), the product \(\lambda\mathbf{a}\) satisfies:

  • \(|\lambda\mathbf{a}| = |\lambda||\mathbf{a}|\)
  • \(\lambda\mathbf{0} = \mathbf{0}\)
  • \((-m)\mathbf{a} = m(-\mathbf{a}) = -(m\mathbf{a})\)
  • \((mn)\mathbf{a} = m(n\mathbf{a})\)
  • \((m+n)\mathbf{a} = m\mathbf{a} + n\mathbf{a}\)
  • \(m(\mathbf{a} + \mathbf{b}) = m\mathbf{a} + m\mathbf{b}\)
Components of a Vector

In 2D: For point \(P(x, y)\), \(\overrightarrow{OP} = x\hat{i} + y\hat{j}\)

In 3D: For point \(P(x, y, z)\), \(\overrightarrow{OP} = x\hat{i} + y\hat{j} + z\hat{k}\)

Vector joining two points \(P_1(x_1, y_1, z_1)\) and \(P_2(x_2, y_2, z_2)\):

\[\overrightarrow{P_1P_2} = (x_2 - x_1)\hat{i} + (y_2 - y_1)\hat{j} + (z_2 - z_1)\hat{k}\] \[|\overrightarrow{P_1P_2}| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}\]

Position Vectors, Section Formulae & Centres of a Triangle

The position vector of point \(P\) w.r.t. a fixed origin \(O\) is \(\overrightarrow{OP}\).

For any vector \(\overrightarrow{PQ}\): \(\overrightarrow{PQ} = \text{PV of } Q - \text{PV of } P\)

Collinear points: \(A, B, C\) are collinear \(\Leftrightarrow\) \(\overrightarrow{AB} = \lambda\,\overrightarrow{BC}\) for some scalar \(\lambda \ne 0\).

Section Formulae

If \(A\) and \(B\) have position vectors \(\mathbf{a}\) and \(\mathbf{b}\), then the point \(P\) dividing \(AB\):

  • Internally in ratio \(m:n\): \[\mathbf{r} = \frac{m\mathbf{b} + n\mathbf{a}}{m + n}\]
  • Mid-point of \(AB\): \[\mathbf{r} = \frac{\mathbf{a} + \mathbf{b}}{2}\]
  • Externally in ratio \(m:n\): \[\mathbf{r} = \frac{m\mathbf{b} - n\mathbf{a}}{m - n}\]
Position Vectors of Centres of a Triangle

Let \(\mathbf{a}, \mathbf{b}, \mathbf{c}\) be the position vectors of vertices \(A, B, C\) of \(\triangle ABC\).

  • Centroid \(G\): \[\mathbf{g} = \frac{\mathbf{a} + \mathbf{b} + \mathbf{c}}{3}\]
  • Incentre \(I\): (where \(a = BC\), \(b = CA\), \(c = AB\)) \[\mathbf{i} = \frac{a\,\mathbf{a} + b\,\mathbf{b} + c\,\mathbf{c}}{a + b + c}\]
  • Orthocentre \(H\): \[\mathbf{h} = \frac{(\tan A)\,\mathbf{a} + (\tan B)\,\mathbf{b} + (\tan C)\,\mathbf{c}}{\tan A + \tan B + \tan C}\]
Linear Combination, Collinearity & Coplanarity

Linear Combination: \(x\mathbf{a} + y\mathbf{b} + z\mathbf{c} + \cdots\) is a linear combination of \(\mathbf{a}, \mathbf{b}, \mathbf{c}, \ldots\)

Collinearity of 3 points (PVs \(\mathbf{a}, \mathbf{b}, \mathbf{c}\)): They are collinear iff there exist scalars \(x, y, z\) (not all zero) such that \(x\mathbf{a} + y\mathbf{b} + z\mathbf{c} = \mathbf{0}\) and \(x + y + z = 0\).

Coplanarity of 4 points (PVs \(\mathbf{a}, \mathbf{b}, \mathbf{c}, \mathbf{d}\)): They are coplanar iff there exist scalars \(x, y, z, t\) (not all zero) such that \(x\mathbf{a} + y\mathbf{b} + z\mathbf{c} + t\mathbf{d} = \mathbf{0}\) and \(x + y + z + t = 0\).

Linearly Dependent & Independent Vectors
  • Linearly Dependent: \(\mathbf{a}, \mathbf{b}, \mathbf{c}, \ldots\) are linearly dependent if there exist scalars \(x, y, z, \ldots\) (not all zero) such that \(x\mathbf{a} + y\mathbf{b} + z\mathbf{c} + \cdots = \mathbf{0}\).
  • Linearly Independent: \(x\mathbf{a} + y\mathbf{b} + z\mathbf{c} = \mathbf{0} \Rightarrow x = y = z = 0\).
  • Two non-zero, non-collinear vectors are linearly independent.
  • Three non-zero, non-coplanar vectors are linearly independent.
  • More than three vectors are always linearly dependent.

Scalar (Dot) Product of Two Vectors

For non-zero vectors \(\mathbf{a}\) and \(\mathbf{b}\), the scalar product is:

\[\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos\theta, \quad 0 \le \theta \le \pi\]
Properties of Dot Product
  • Angle between like vectors: \(\theta = 0\); angle between unlike vectors: \(\theta = \pi\).
  • If either \(\mathbf{a}\) or \(\mathbf{b}\) is null, then \(\mathbf{a} \cdot \mathbf{b} = 0\).
  • For unit vectors: \(\hat{a} \cdot \hat{b} = \cos\theta\).
  • Commutative: \(\mathbf{a} \cdot \mathbf{b} = \mathbf{b} \cdot \mathbf{a}\)
  • For mutually perpendicular unit vectors \(\hat{i}, \hat{j}, \hat{k}\): \[\hat{i}\cdot\hat{i} = \hat{j}\cdot\hat{j} = \hat{k}\cdot\hat{k} = 1, \quad \hat{i}\cdot\hat{j} = \hat{j}\cdot\hat{k} = \hat{k}\cdot\hat{i} = 0\]
  • Distributive: \(\mathbf{a}\cdot(\mathbf{b}+\mathbf{c}) = \mathbf{a}\cdot\mathbf{b} + \mathbf{a}\cdot\mathbf{c}\)   and   \((\mathbf{a}+\mathbf{b})\cdot\mathbf{c} = \mathbf{a}\cdot\mathbf{c} + \mathbf{b}\cdot\mathbf{c}\)
  • \((m\mathbf{a})\cdot\mathbf{b} = \mathbf{a}\cdot(m\mathbf{b}) = m(\mathbf{a}\cdot\mathbf{b})\) for any scalar \(m\).
  • For \(\mathbf{a} = a_1\hat{i}+a_2\hat{j}+a_3\hat{k}\): \(|\mathbf{a}|^2 = \mathbf{a}\cdot\mathbf{a} = a_1^2+a_2^2+a_3^2\)
Angle Between Two Vectors & Projection

For \(\mathbf{a} = a_1\hat{i}+a_2\hat{j}+a_3\hat{k}\) and \(\mathbf{b} = b_1\hat{i}+b_2\hat{j}+b_3\hat{k}\):

\[\cos\theta = \frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}||\mathbf{b}|} = \frac{a_1b_1+a_2b_2+a_3b_3}{\sqrt{a_1^2+a_2^2+a_3^2}\,\sqrt{b_1^2+b_2^2+b_3^2}}\]

Perpendicularity condition: \(\mathbf{a} \perp \mathbf{b} \Leftrightarrow \mathbf{a}\cdot\mathbf{b} = 0\) (for non-zero vectors)

Projection of \(\mathbf{a}\) on \(\mathbf{b}\): \(\displaystyle\frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{b}|}\)

Projection of \(\mathbf{b}\) on \(\mathbf{a}\): \(\displaystyle\frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}|}\)

Component of \(\mathbf{a}\) along \(\mathbf{b}\): \(\displaystyle\frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{b}|^2}\,\mathbf{b}\)

Component of \(\mathbf{a}\) perpendicular to \(\mathbf{b}\): \(\displaystyle\mathbf{a} - \frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{b}|^2}\,\mathbf{b}\)

Important Results of Dot Product
  • \((\mathbf{a}+\mathbf{b})\cdot(\mathbf{a}-\mathbf{b}) = |\mathbf{a}|^2 - |\mathbf{b}|^2\)
  • \(|\mathbf{a}+\mathbf{b}|^2 = |\mathbf{a}|^2 + |\mathbf{b}|^2 + 2\,\mathbf{a}\cdot\mathbf{b}\)
  • \(|\mathbf{a}-\mathbf{b}|^2 = |\mathbf{a}|^2 + |\mathbf{b}|^2 - 2\,\mathbf{a}\cdot\mathbf{b}\)
  • \(|\mathbf{a}+\mathbf{b}|^2 + |\mathbf{a}-\mathbf{b}|^2 = 2(|\mathbf{a}|^2 + |\mathbf{b}|^2)\)
  • \(|\mathbf{a}+\mathbf{b}|^2 - |\mathbf{a}-\mathbf{b}|^2 = 4\,\mathbf{a}\cdot\mathbf{b} \;\Rightarrow\; \mathbf{a}\cdot\mathbf{b} = \dfrac{|\mathbf{a}+\mathbf{b}|^2 - |\mathbf{a}-\mathbf{b}|^2}{4}\)
  • If \(|\mathbf{a}+\mathbf{b}| = |\mathbf{a}| + |\mathbf{b}|\), then \(\mathbf{a}\) is parallel to \(\mathbf{b}\).
  • If \(|\mathbf{a}+\mathbf{b}| = |\mathbf{a}-\mathbf{b}|\), then \(\mathbf{a} \perp \mathbf{b}\).
  • Cauchy-Schwarz: \((\mathbf{a}\cdot\mathbf{b})^2 \le |\mathbf{a}|^2|\mathbf{b}|^2\)
Work Done by a Force

Work done by force \(\mathbf{F}\) over displacement \(\mathbf{S}\):

\[W = \mathbf{F} \cdot \mathbf{S}\]

For \(n\) forces \(\mathbf{F}_1, \mathbf{F}_2, \ldots, \mathbf{F}_n\) over displacement \(\mathbf{S}\), total work done:

\[W = \sum_{i=1}^{n} \mathbf{F}_i \cdot \mathbf{S} = \mathbf{R} \cdot \mathbf{S}\]

where \(\mathbf{R}\) is the resultant force.

Vector (Cross) Product of Two Vectors

The vector product of \(\mathbf{a}\) and \(\mathbf{b}\) is:

\[\mathbf{a} \times \mathbf{b} = |\mathbf{a}||\mathbf{b}|\sin\theta\;\hat{n}\]

where \(\hat{n}\) is the unit vector perpendicular to both \(\mathbf{a}\) and \(\mathbf{b}\), determined by the right-hand rule.

Properties of Cross Product

For \(\mathbf{a} = a_1\hat{i}+a_2\hat{j}+a_3\hat{k}\) and \(\mathbf{b} = b_1\hat{i}+b_2\hat{j}+b_3\hat{k}\):

\[\mathbf{a}\times\mathbf{b} = \begin{vmatrix}\hat{i} & \hat{j} & \hat{k}\\ a_1 & a_2 & a_3\\ b_1 & b_2 & b_3\end{vmatrix}\]
  • If \(\mathbf{a} = \mathbf{b}\) or \(\mathbf{a} \parallel \mathbf{b}\), then \(\mathbf{a}\times\mathbf{b} = \mathbf{0}\) (since \(\sin\theta = 0\)).
  • Unit vector perpendicular to both \(\mathbf{a}\) and \(\mathbf{b}\): \(\;\hat{n} = \dfrac{\mathbf{a}\times\mathbf{b}}{|\mathbf{a}\times\mathbf{b}|}\)
  • Vector product of two parallel/collinear vectors is \(\mathbf{0}\).
  • \(\mathbf{a}\times\mathbf{b} = \mathbf{0} \Leftrightarrow \mathbf{a} = \mathbf{0}\) or \(\mathbf{b} = \mathbf{0}\) or \(\mathbf{a} \parallel \mathbf{b}\).
  • If \(\theta = 90°\): \(|\mathbf{a}\times\mathbf{b}| = |\mathbf{a}||\mathbf{b}|\)
  • For unit vectors: \(|\mathbf{a}\times\mathbf{b}| = \sin\theta\)
  • Anti-commutative: \(\mathbf{a}\times\mathbf{b} = -\mathbf{b}\times\mathbf{a}\)
  • Distributive: \(\mathbf{a}\times(\mathbf{b}+\mathbf{c}) = \mathbf{a}\times\mathbf{b} + \mathbf{a}\times\mathbf{c}\)
  • For \(\hat{i}, \hat{j}, \hat{k}\): \[\hat{i}\times\hat{i} = \hat{j}\times\hat{j} = \hat{k}\times\hat{k} = \mathbf{0}\] \[\hat{i}\times\hat{j} = \hat{k},\quad \hat{j}\times\hat{k} = \hat{i},\quad \hat{k}\times\hat{i} = \hat{j}\] \[\hat{j}\times\hat{i} = -\hat{k},\quad \hat{k}\times\hat{j} = -\hat{i},\quad \hat{i}\times\hat{k} = -\hat{j}\]
Area Formulas Using Cross Product
  • Area of \(\triangle ABC\): \[\frac{1}{2}|\overrightarrow{AB}\times\overrightarrow{AC}| = \frac{1}{2}|\overrightarrow{BC}\times\overrightarrow{BA}| = \frac{1}{2}|\overrightarrow{CB}\times\overrightarrow{CA}|\]
  • Area of \(\triangle ABC\) with PVs \(\mathbf{a}, \mathbf{b}, \mathbf{c}\): \[\frac{1}{2}|\mathbf{a}\times\mathbf{b} + \mathbf{b}\times\mathbf{c} + \mathbf{c}\times\mathbf{a}|\]
  • Points \(\mathbf{a}, \mathbf{b}, \mathbf{c}\) are collinear iff: \(\mathbf{a}\times\mathbf{b} + \mathbf{b}\times\mathbf{c} + \mathbf{c}\times\mathbf{a} = \mathbf{0}\)
  • Area of parallelogram with adjacent sides \(\mathbf{a}\) and \(\mathbf{b}\): \(|\mathbf{a}\times\mathbf{b}|\)
  • Area of parallelogram with diagonals \(\mathbf{a}\) and \(\mathbf{b}\): \(\dfrac{1}{2}|\mathbf{a}\times\mathbf{b}|\)
  • Area of quadrilateral ABCD: \(\dfrac{1}{2}|\overrightarrow{AC}\times\overrightarrow{BD}|\)
Moment of a Force

Vector moment (torque) of force \(\mathbf{F}\) about point \(O\):

\[\mathbf{M} = \mathbf{r} \times \mathbf{F}\]

where \(\mathbf{r}\) is the position vector of the point of application referred to \(O\).

Moment of force \(\mathbf{F}\) about a line \(l\) (with unit vector \(\hat{a}\) and point \(O\) on \(l\)): \[= (\overrightarrow{OA} \times \mathbf{F}) \cdot \hat{a}\]

Moment of a couple (forces \(\mathbf{F}\) and \(-\mathbf{F}\) at points \(Q\) and \(P\)): \[= \overrightarrow{PQ} \times \mathbf{F}\]

Scalar Triple Product

For vectors \(\mathbf{a}, \mathbf{b}, \mathbf{c}\), the scalar triple product is defined as:

\[[\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = (\mathbf{a}\times\mathbf{b})\cdot\mathbf{c}\]

In component form, for \(\mathbf{a} = a_1\hat{i}+a_2\hat{j}+a_3\hat{k}\), etc.:

\[[\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = \begin{vmatrix} a_1 & a_2 & a_3 \\ b_1 & b_2 & b_3 \\ c_1 & c_2 & c_3 \end{vmatrix}\]

Geometrical meaning: \([\mathbf{a}\;\mathbf{b}\;\mathbf{c}]\) represents the volume of the parallelepiped whose co-terminus edges are \(\mathbf{a}, \mathbf{b}, \mathbf{c}\).

Properties of Scalar Triple Product
  • Dot and cross are interchangeable: \((\mathbf{a}\times\mathbf{b})\cdot\mathbf{c} = \mathbf{a}\cdot(\mathbf{b}\times\mathbf{c})\)
  • Cyclic property (unchanged under cyclic permutation): \[[\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = [\mathbf{b}\;\mathbf{c}\;\mathbf{a}] = [\mathbf{c}\;\mathbf{a}\;\mathbf{b}]\]
  • Anti-cyclic (sign reverses): \([\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = -[\mathbf{a}\;\mathbf{c}\;\mathbf{b}]\)
  • Vanishes if any two vectors are equal: \([\mathbf{a}\;\mathbf{a}\;\mathbf{b}] = 0\)
  • Vanishes if any two vectors are parallel/collinear.
  • Scalar factor: \([x\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = x[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]\) and \([xyz\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = xyz[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]\)
  • Linearity: \([(\mathbf{a}+\mathbf{d})\;\mathbf{b}\;\mathbf{c}] = [\mathbf{a}\;\mathbf{b}\;\mathbf{c}] + [\mathbf{d}\;\mathbf{b}\;\mathbf{c}]\)
  • \([\hat{i}\;\hat{j}\;\hat{k}] = 1\)
  • \((\mathbf{a}\times\mathbf{b})\cdot(\mathbf{c}\times\mathbf{d}) = \begin{vmatrix}\mathbf{a}\cdot\mathbf{c} & \mathbf{a}\cdot\mathbf{d}\\ \mathbf{b}\cdot\mathbf{c} & \mathbf{b}\cdot\mathbf{d}\end{vmatrix}\)
  • \([\mathbf{a}\;\mathbf{b}\;\mathbf{c}][\mathbf{u}\;\mathbf{v}\;\mathbf{w}] = \begin{vmatrix}\mathbf{a}\cdot\mathbf{u} & \mathbf{a}\cdot\mathbf{v} & \mathbf{a}\cdot\mathbf{w}\\ \mathbf{b}\cdot\mathbf{u} & \mathbf{b}\cdot\mathbf{v} & \mathbf{b}\cdot\mathbf{w}\\ \mathbf{c}\cdot\mathbf{u} & \mathbf{c}\cdot\mathbf{v} & \mathbf{c}\cdot\mathbf{w}\end{vmatrix}\)
  • Three non-zero vectors \(\mathbf{a}, \mathbf{b}, \mathbf{c}\) are coplanar iff \([\mathbf{a}\;\mathbf{b}\;\mathbf{c}] = 0\).
  • Four points \(A, B, C, D\) (PVs \(\mathbf{a}, \mathbf{b}, \mathbf{c}, \mathbf{d}\)) are coplanar iff \([\mathbf{b}-\mathbf{a},\;\mathbf{c}-\mathbf{a},\;\mathbf{d}-\mathbf{a}] = 0\).

Vector Triple Product

For vectors \(\mathbf{a}, \mathbf{b}, \mathbf{c}\), the vector triple products are:

\[\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) = (\mathbf{a}\cdot\mathbf{c})\,\mathbf{b} - (\mathbf{a}\cdot\mathbf{b})\,\mathbf{c}\] \[(\mathbf{a}\times\mathbf{b})\times\mathbf{c} = (\mathbf{a}\cdot\mathbf{c})\,\mathbf{b} - (\mathbf{b}\cdot\mathbf{c})\,\mathbf{a}\]
Properties of Vector Triple Product
  • \(\mathbf{r} = \mathbf{a}\times(\mathbf{b}\times\mathbf{c})\) is perpendicular to \(\mathbf{a}\) and lies in the plane of \(\mathbf{b}\) and \(\mathbf{c}\).
  • Cross product is not associative: \(\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) \ne (\mathbf{a}\times\mathbf{b})\times\mathbf{c}\) in general.
  • \(\mathbf{a}\times(\mathbf{b}\times\mathbf{c}) = (\mathbf{a}\times\mathbf{b})\times\mathbf{c}\) if and only if \(\dfrac{\mathbf{a}\cdot\mathbf{c}}{\mathbf{b}\cdot\mathbf{c}} = \dfrac{\mathbf{a}\cdot\mathbf{b}}{\mathbf{b}\cdot\mathbf{c}}\), i.e. \(\mathbf{b}\cdot\mathbf{c} = \mathbf{a}\cdot\mathbf{b}\) or \(\mathbf{a}\) and \(\mathbf{c}\) are collinear.

Reciprocal System of Vectors

Let \(\mathbf{a}, \mathbf{b}, \mathbf{c}\) be three non-coplanar vectors. Their reciprocal system \(\mathbf{a}', \mathbf{b}', \mathbf{c}'\) is defined as:

\[\mathbf{a}' = \frac{\mathbf{b}\times\mathbf{c}}{[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]}, \qquad \mathbf{b}' = \frac{\mathbf{c}\times\mathbf{a}}{[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]}, \qquad \mathbf{c}' = \frac{\mathbf{a}\times\mathbf{b}}{[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]}\]
Properties of Reciprocal System
  • \(\mathbf{a}\cdot\mathbf{a}' = \mathbf{b}\cdot\mathbf{b}' = \mathbf{c}\cdot\mathbf{c}' = 1\)
  • \(\mathbf{a}\cdot\mathbf{b}' = \mathbf{a}\cdot\mathbf{c}' = \mathbf{b}\cdot\mathbf{a}' = \mathbf{b}\cdot\mathbf{c}' = \mathbf{c}\cdot\mathbf{a}' = \mathbf{c}\cdot\mathbf{b}' = 0\)
  • \([\mathbf{a}'\;\mathbf{b}'\;\mathbf{c}'] = \dfrac{1}{[\mathbf{a}\;\mathbf{b}\;\mathbf{c}]}\)
  • \(\mathbf{a} = \dfrac{\mathbf{b}'\times\mathbf{c}'}{[\mathbf{a}'\;\mathbf{b}'\;\mathbf{c}']}\), \(\;\mathbf{b} = \dfrac{\mathbf{c}'\times\mathbf{a}'}{[\mathbf{a}'\;\mathbf{b}'\;\mathbf{c}']}\), \(\;\mathbf{c} = \dfrac{\mathbf{a}'\times\mathbf{b}'}{[\mathbf{a}'\;\mathbf{b}'\;\mathbf{c}']}\) (so \(\mathbf{a},\mathbf{b},\mathbf{c}\) is reciprocal to \(\mathbf{a}',\mathbf{b}',\mathbf{c}'\))
  • The orthonormal triad \(\hat{i}, \hat{j}, \hat{k}\) forms a self-reciprocal system.
  • Any vector \(\mathbf{r}\) can be expressed as: \[\mathbf{r} = (\mathbf{r}\cdot\mathbf{a}')\,\mathbf{a} + (\mathbf{r}\cdot\mathbf{b}')\,\mathbf{b} + (\mathbf{r}\cdot\mathbf{c}')\,\mathbf{c}\]
