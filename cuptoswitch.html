Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Check whether a number is positive, negative or zero using if-else.
    Input: -5
    Output: Negative
  2. Check if a number is even or odd.
    Input: 7
    Output: Odd
  3. Calculate simple interest. Formula: SI = (P×R×T)/100
    Input: P=1000, R=5, T=2
    Output: 100
  4. Find the greatest of two numbers using if-else.
    Input: 12, 20
    Output: 20
  5. Check vowel or consonant using switch case.
    Input: a
    Output: Vowel
  6. Write a program to display a calculator using switch (Add, Sub, Mul, Div).
    Input: 5, 3, +
    Output: 8
  7. Find the ASCII value of a character.
    Input: A
    Output: 65
