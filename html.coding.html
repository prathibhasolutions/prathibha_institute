HTML Practice Tasks

1. Write HTML to display a paragraph and a heading.
<h1>Welcome to HTML</h1> <p>This is a paragraph.</p>
2. Write HTML to add a link that opens in a new tab.
<a href="https://example.com" target="_blank">Visit Example</a>
3. Write all types of HTML headings and one paragraph.
<h1>Heading 1</h1> <h2>Heading 2</h2> <h3>Heading 3</h3> <h4>Heading 4</h4> <h5>Heading 5</h5> <h6>Heading 6</h6> <p>This is a paragraph.</p>
4. Make a paragraph red and bold using inline style.
<p style="color:red; font-weight:bold;">This is styled text.</p>
5. Add a blockquote and a comment in HTML.
<!-- This is a comment --> <blockquote> HTML is a markup language. </blockquote>
6. Write a paragraph and color it green using CSS class.
<style> .green-text { color: green; } </style> <p class="green-text">This is green text.</p>
7. Insert a clickable image that links to Google.
<a href="https://google.com"> <img src="https://via.placeholder.com/100" alt="Google"> </a>
8. Add a favicon and set page title.
<head> <title>My Page</title> <link rel="icon" href="favicon.ico" type="image/x-icon"> </head>
9. Create a table with 2 rows and 2 columns.
<table border="1"> <tr><td>A1</td><td>B1</td></tr> <tr><td>A2</td><td>B2</td></tr> </table>
10. Create an unordered list with 3 items.
<ul> <li>Apple</li> <li>Banana</li> <li>Cherry</li> </ul>
11. Create a div with a class and an ID.
<div id="box1" class="highlight"> Content inside div. </div>
12. Embed a website using iframe.
<iframe src="https://example.com" width="300" height="200"></iframe>
13. Show relative path for an image.
<img src="images/photo.jpg" alt="Photo">
14. Add meta tag for responsive layout.
<meta name="viewport" content="width=device-width, initial-scale=1.0">
15. Create an ordered list of 3 items.
<ol> <li>Step One</li> <li>Step Two</li> <li>Step Three</li> </ol>
16. Insert an input field and button.
<input type="text" placeholder="Enter name"> <button>Submit</button>
17. Create a horizontal line and a line break.
<hr> <br>
18. Make bold and italic text.
<b>Bold</b> and <i>Italic</i>
19. Add a label and a checkbox.
<label> <input type="checkbox"> I agree </label>
20. Add an image with width 200px.
<img src="logo.png" width="200" alt="Logo">
21. Add title and alt to image.
<img src="pic.jpg" alt="Mountain" title="Nature">
22. Use span tag with inline color.
<p>This is <span style="color:blue">blue text</span></p>
23. Add a dropdown (select) menu.
<select> <option>HTML</option> <option>CSS</option> </select>
24. Write doctype declaration for HTML5.
<!DOCTYPE html>
25. Create a button with an alert using onclick.
<button onclick="alert('Hello!')">Click Me</button>
