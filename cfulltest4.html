Section A: Programming Questions

Attempt any SEVEN of the following questions. Each question carries 10 marks. (7 x 10 = 70 Marks)

1. Write a C program to check whether a given number is prime or not.

Example: 
Enter a number: 29
29 is a prime number.

2. Write a C program to find the factorial of a number using a `while` loop.

Example: 
Enter a number: 5
Factorial of 5 is 120

3. Write a C program to reverse a given string without using the `strrev()` function.

Example: 
Enter a string: Hello
Reversed string: olleH

4. Write a C program to check if an element is present in an array.

Example Input & Output: 
Array: {10, 20, 30, 40, 50}
Enter element to search : 20
Yes

5. Write a recursive C function to compute the Fibonacci series up to the nth term.

Example: 
Enter number of terms: 6
Fibonacci Series: 0 1 1 2 3 5

6. Define a structure `Student` with fields `id`, `name` (string), and `marks`. Write a function to input data for two students and display their details.

Example Output: 
Student 1: ID=101, Name=Ravi, Marks=85
Student 2: ID=102, Name=Anita, Marks=92

7. Write a program to print the multiplication table of a given number using nested loops from 1 to 10.

Example (for 3): 
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
...
3 x 10 = 30

8. Write a C program to read a file named "data.txt" and display the number of lines in it.

Instructions: 
1. Create "data.txt" with multiple lines of text.
2. Run the program.
3. Output: Total lines in file: [number]

9. Write a function in C to check if a string is a palindrome.

Example: 
Enter a string: madam
madam is a palindrome.

10. Write a C program to find the transpose of a 3x3 matrix.

Example: 
// Original matrix:
// 1 2 3
// 4 5 6
// 7 8 9
// Transpose:
// 1 4 7
// 2 5 8
// 3 6 9
