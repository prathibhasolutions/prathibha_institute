C Language Exam – If-Else & Loops

Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Write a program to check if a number is even or odd using if-else.
    Example:
    Input: 4
    Output: Even
  2. Write a program to find the largest of three numbers using if-else.
    Example:
    Input: 10, 25, 15
    Output: 25 is the largest
  3. Write a program to print the multiplication table of a number using a loop.
    Example:
    Input: 5
    Output: 5 10 15 20 25 30 35 40 45 50
  4. Write a program to calculate the sum of digits of a number using loop.
    Example:
    Input: 123
    Output: 6
  5. Write a program to check whether a number is prime using loop.
    Example:
    Input: 7
    Output: Prime
  6. Write a program to print all numbers from 1 to 100 divisible by both 3 and 5.
    Example:
    Output: 15 30 45 60 75 90
  7. Write a program to find factorial of a number using a loop.
    Example:
    Input: 5
    Output: 120
  8. Write a program to print a right-angled triangle pattern using nested loops.
    Example:
    Input: 3
    Output:
    *
    **
    ***
  9. Write a program to print a pyramid pattern using nested loops.
    Example:
    Input: 3
    Output:
       *
      ***
     *****
  10. Write a program to count and display the number of even and odd numbers in a given range.
    Example:
    Input: 1 to 10
    Output: Even: 5, Odd: 5
