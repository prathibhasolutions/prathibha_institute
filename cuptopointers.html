C Programming Exam - Set 3

Multiple Choice Questions (MCQs)

Programming Questions


  1. Write a C program to check whether a number is positive, negative or zero using if-else.
  2. Write a C program to print the sum of all even numbers between 1 and 50 using loop.
  3. Write a program to calculate factorial of a number using loop.
  4. Write a C program to print a triangle pattern using nested loops.
  5. Write a program to find the maximum element in an integer array.
  6. Write a C program to count the number of vowels in a string.
  7. Write a C program to reverse a string without using strrev().
  8. Write a C program to copy one string to another using pointers.
  9. Write a program to swap two numbers using pointers.
  10. Write a C program to print all prime numbers between 1 and 100.
