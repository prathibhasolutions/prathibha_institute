Java Programming Exam - Set 4

Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Write a Java program to check if a number has same first and last digits.
    Example: Input: 1371
    Output: Yes
  2. Write a program using nested loops to print a diamond pattern.
    Example: Input: 3
    Output:
       *
      ***
    *****
      ***
       *
  3. Write a recursive function to calculate the GCD of two numbers.
    Example: Input: 18, 24
    Output: 6
  4. Write a function that counts and returns the largest digit in an integer.
    Example: Input: 42381
    Output: 8
  5. Write a program to print all prime numbers between 1 and 100 using functions and loops.
    Example: Output: 2 3 5 7 11 ...
  6. Write a program to reverse each word in a given sentence using functions.
    Example: Input: Java is fun
    Output: avaJ si nuf
  7. Write a Java program to calculate the power of a number using recursion.
    Example: Input: base = 2, exponent = 4
    Output: 16
  8. Write a program to check whether a number is an Perfect number or not.(If the sum of its factors excluding the number is equal to the number itself, then such numbers are called Perfect numbers) )
    Example: Input: 6
    Output: Perfect Number
  9. Write a Java function that prints the first N terms of the Fibonacci series using recursion.
    Example: Input: 6
    Output: 0 1 1 2 3 5
  10. Write a Java program to print the sum of the digits of a number until it is a single digit.
    Example: Input: 943
    Output: 7
