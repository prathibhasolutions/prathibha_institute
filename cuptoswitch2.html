C Language Exam - Set 5

Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs

  1. Declare variables of int, float, and char types and print them.
    Input: 5, 3.2, A
    Output: 5 3.20 A
  2. Check whether a given number is divisible by 3 using if-else.
    Input: 9
    Output: Yes
  3. Calculate the area of a rectangle (length * breadth).
    Input: 4, 5
    Output: 20
  4. Use switch to determine the weekday based on number (1-7).
    Input: 1
    Output: Monday
  5. Find the greatest of three numbers using if-else ladder.
    Input: 5, 8, 2
    Output: 8
  6. Check whether a character is uppercase or lowercase.
    Input: G
    Output: Uppercase
  7. Write a calculator program to perform +, -, *, / using switch.
    Input: 6, 2, *
    Output: 12

Theory Questions

  1. What are arithmetic operators in C? Explain with examples.
  2. Define switch-case. Write its syntax and one use case.
  3. Explain data types in C with their sizes and example usage.
