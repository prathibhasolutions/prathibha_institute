C Language MCQs and Programming Questions (Set 1)


Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Write a C program to find the largest element in a 1D array.
    Example:
    Input: [3, 5, 7, 2]
    Output: 7
  2. Write a program to calculate the sum of elements in an array.
    Example:
    Input: [1, 2, 3, 4]
    Output: 10
  3. Write a program to reverse a string without using library functions.
    Example:
    Input: hello
    Output: olleh
  4. Write a program to check if a string is a palindrome.
    Example:
    Input: madam
    Output: Yes
  5. Write a program to copy one string to another.
    Example:
    Input: "C Language"
    Output: "C Language"
  6. Write a program to find the transpose of a 2D matrix.
    Example:
    Input: [[1,2],[3,4]]
    Output: [[1,3],[2,4]]
  7. Write a program to count vowels in a string.
    Example:
    Input: education
    Output: 5
  8. Write a program to insert an element at a given position in an array.
    Example:
    Input: [1, 2, 4], insert 3 at pos 2
    Output: [1, 2, 3, 4]
  9. Write a program to merge two arrays into a third array.
    Example:
    Input: [1,2], [3,4]
    Output: [1,2,3,4]
  10. Write a program to count even and odd numbers in an array.
    Example:
    Input: [1,2,3,4]
    Output: Even=2, Odd=2
