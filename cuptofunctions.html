C Programming Exam - Set 4

Multiple Choice Questions (MCQs)

Programming Questions with Example Outputs


  1. Write a program to check whether a number is even or odd using if-else.
    Example: Input: 8
    Output: Even
  2. Write a C program to print all even numbers between 1 and 100 using a loop.
    Example: Output: 2 4 6 ... 100
  3. Write a program to calculate factorial of a number using recursion.
    Example: Input: 5
    Output: 120
  4. Write a function to find the sum of all elements in an array.
    Example: Input: [2, 5, 1]
    Output: 8
  5. Write a C program to reverse a string using a function.
    Example: Input: hello
    Output: olleh
  6. Write a program using pointer to swap two numbers.
    Example: Input: a = 3, b = 5
    Output: a = 5, b = 3
  7. Write a program to print a number pyramid using nested loops.
    Example:
    Input: 3
    Output:
    1
    1 2
    1 2 3
  8. Write a program to count the number of vowels in a string using function.
    Example: Input: education
    Output: 5
  9. Write a recursive function to print Fibonacci series up to n terms.
    Example: Input: 5
    Output: 0 1 1 2 3
  10. Write a program to find the maximum element in a 1D array.
    Example: Input: [10, 22, 5, 13]
    Output: 22
